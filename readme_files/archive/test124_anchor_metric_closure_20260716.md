# Test124：junction 度量闭包上的 D-block 上界

更新时间：2026-07-16。Test124 已从源码和构建目标中撤回；本文保存其理论边界与 Release/O2 实验，不作为当前主线结论。除第 5 节明确标注的 Toronto 完整运行外，其余数字来自已撤回二进制的层截止探针，不能当作最终 GST 时间或答案。

## 1. 研究问题

Test121 只允许 rooted D-block 沿一棵固定的最短路父树汇合。Test124 检验一个更宽的结构族：保留同一批 junction sites，但不固定父树，而是在这些 sites 与永久锚路径组成的度量闭包中自由选择连接拓扑。目标是判断 Test121 的主要损失是否来自父树拓扑过窄。

该机制不改变 permanent-anchor 状态定义、ordinary/A 有序行、精确停止条件或图本身，也不使用 Hash。它只在每个自然 D 层结束后计算一个可行上界，因此没有违反 `agent.md` 第六条所禁止的数据集、固定层号、密度或运行时刻特判。

## 2. 方法与正确性

令 `X` 为现有 junction sites，并增加一个表示已付费永久锚路径的虚根。对任意两点 `x,y in X`，用原图最短路距离 `d(x,y)` 作为闭包边长；对每个非锚组子集 `B`，已有 rooted D row 给出在 site `x` 接入该 block 的可行代价 `c_x(B)`。局部规范化划分先计算在同一 site 汇合的代价：

```text
L_x(0) = 0,
L_x(M) = min { L_x(M\B) + c_x(B) : lowbit(M) in B subseteq M }.
```

随后交替执行同点不交子集合并与度量闭包传播：

```text
F_x(M) <- min_{A proper subset of M} F_x(A) + F_x(M\A),
F_x(M) <- min_y F_y(M) + d(y,x).
```

虚根处的全掩码值再加永久锚路径成本，得到候选上界。每个局部 block 都有真实 rooted D 见证；合并只取见证子图的并，传播则加入一条真实最短路。因此每个有限 DP 值都对应原图中的可行连通子图，重复边至多被重复计费，不会低估真实并集成本。最终值是合法 feasible upper，可以安全写回 incumbent。由于 Test121 的父树边均能由度量闭包路径表示，Test124 的候选理论上不弱于 Test121。

这一内层递推属于经典 Steiner subset DP / metric closure 范式，与 [Dreyfus--Wagner, *The Steiner Problem in Graphs*](https://doi.org/10.1002/net.3230010302) 同源。将它放在永久锚路径、junction sites 和已有 D rows 上作为层末上界，是本仓库的组合实验；本文不把 subset recurrence 本身称为原创贡献。

## 4. 自然层边界证据

Toronto `g13 q1--q5` 的 D3 截止 panel 中，Test124 相对 Test121 的 D2 values 合计下降 `4.64%`，但到 D3 只剩约 `0.91%`；D3 截止总 wall 已基本中性。DBLP `g15 q33` 的 D1 只读门得到 `10.2231529369`，优于 Test121 当时的 `10.2642201136`；闭包含 `17` 个 sites，准备耗时 `2.172s`，单层 subset DP 耗时 `0.049s`。

q33 D2 写回门中，两种方法最终都得到 `9.9770319196`，Test124 只因 D1 更早的较强 incumbent 减少一小部分 D2 工作：

该 D2 截止 query wall 为 `454.556s`，query peak RSS 为 `2841.160MiB`。收益已随层数快速衰减，因此没有启动 DBLP D3、D4 或完整 q33。

## 6. 撤回结论

Test124 证明固定父树并非绝对完备，但更自由的 junction 拓扑只在早期层给出小幅改善，不能持续改变高层状态空间；额外全图最短路闭包和 DP 扫描又使完整跨询问时间回退。它属于已知风格且对 baseline 也较容易复用，不适合作为论文主线突破。因此专用实现、统计字段与五个构建目标全部撤回，只保留通用 D1/D2/D3 自然边界探针。后续不再沿“同一 sites 上扩大 metric closure”方向叠加设施，而应寻找能直接减少 D4/A6 状态生成或有序行扫描的新锚感知状态接口。
