# Test127：Paid-Pair 见证并集上界

更新时间：2026-07-16。Test127 已从活动探针、构建依赖和命令行入口撤回。它尝试把永久锚框架中的 D2 paid-pair 几何恢复为一个小型真实子图，再在该子图上精确求 GST 上界。方法在五个快速数据版本的 g12 单询问上曾表现很强，但 Toronto g13 q1--q5 固定面板只有 `3/5` 命中精确值；q5 的可行上界比最优值高 `10.93%`。因此它不是完备状态表示，也没有启动 DBLP 长跑。

## 1. 要验证的结构假设

对每个不含永久锚组的组对 `{i,j}`，探针生成精确 D2 行 `D({i,j},v)`。每个 D2 状态都能恢复为三条真实最短路组成的见证树：两个组到某个 split root 的路径，以及 split root 到状态根 `v` 的传播路径。Test127 的假设是：**保留每个 paid attachment 位置上的二维 skyline D2 见证，再加上现有永久锚树，可能已经包含一棵很强甚至最优的完整 GST。**

具体过程如下：

1. 用 Test121 的 junction facility 构造永久锚树，并把树节点连接到永久 root-to-anchor 路径。
2. 以锚树节点为多源，在原图上计算每个顶点最近的 attachment site 及距离。
3. 对每个非锚组对，按 attachment site 分桶；每个桶只保留 `(D2 cost, attachment distance)` 的 Pareto skyline。
4. 恢复所有 skyline 状态的 D2 见证路径、组最短路与 attachment 路径，形成真实边并集；另构造同一顶点集合的原图诱导子图。
5. 分别在见证边并集和诱导子图上运行精确 DPBF。两者都只使用原图真实边，所以得到的答案都是合法可行上界。

这不是图/query 的通用压缩：候选顶点完全来自 permanent-anchor A 框架的 D2 paid geometry。不过探针生成 D2 根时使用了已知最优值和安全 TSP 下界过滤，因而是**对结构假设有利的 oracle 筛查**，不能直接当作在线算法。即便在这种有利条件下失败，也足以否定当前完备性假设。

## 4. 否决结论与保留信息

Test127 不接入 Test121，原因有三：

1. 最近 attachment site 只记录一个离散位置和一个距离，不能表示同一 paid 子树对锚骨架的多个可替代连接位置。
2. 每个 site 内的二维支配只比较 D2 cost 与单一 attachment distance，仍可能删除对其他组或后续大组件连接更有利的见证。
3. 当前结构选择已经借助 exact optimum 做乐观过滤，却仍有显著反例；扩大到在线所有 D2 根只会增加构造成本，不能自动补上完备性证明。

保留的有效信息是：**第二接口的位置必须进入状态相关性；把它压成全局标量会过早支配，而只保留最近 site 也不够。** 若继续研究，应先定义能够表达多个 attachment 选择的受控 profile，并证明它与 A 的离线有序合并兼容；不应通过增加固定数量的 sites、按数据集开关或经验 skyline 宽度继续调参。

本轮没有新增论文引用。受限图上的 DPBF 仅作为离线精确核验器，不属于候选方法，也不作为论文贡献。
