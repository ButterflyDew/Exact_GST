# Test133--136：精确 rooted-row 度量锥下界

更新时间：2026-07-16。该系列尝试把已有普通 `D(B,u)` 有序行压缩为可在任意根读取的 anchor-aware 下界，并将其加入普通 D 与锚定 A 的启发式。四个版本均保持 Test121 的 permanent-anchor A 框架、root-irreducible D branch 和离线有序行，不使用 Hash、数据集分支、固定 `g`、固定层阈值或 wall-time 门控。下界正确，但固定 fast20 与 Toronto g13 多询问面板显示收益不足以覆盖 profile 构造和逐状态读取，因此实现、编译目标与诊断输出均已撤回。

## 1. 可保留的理论结论

对已经精确保存的 rooted row `D(B,.)`、任意行内有限值 `D(B,u)`、任意 hub `t` 和任意目标根 `v`，最短路三角不等式给出：

`D(B,v) >= D(B,u) - dist(u,t) - dist(t,v)`。

因此可以离线保存行 profile：

`C_B(t) = max_u {D(B,u) - dist(u,t)}`，

并在目标根读取下界 `C_B(t)-dist(t,v)`。该式对行中没有保存的根同样成立，因为它只用一个已知精确 rooted value 和图上的合法连接路径推导，不把“缺失值”误作无穷大证书。对多个 hub 取最大仍然合法，而且每个锥关于图边是一致的，可直接进入 label-setting 的下界。

若剩余组集合为 `R`，任意可行续接都包含每个 `B subseteq R` 的 rooted 子问题，所以还可对当前已生成的最大规模子集 profile 取最大。这个推广不改变正确性，但它只提供必要子问题代价，没有表达多个子问题之间的共享边。

永久锚路径 `P` 还给出一个无需额外最短路的特例。令 `delta_P(u)` 为 `u` 到已支付路径的最短距离，`c(P)` 为路径费用，则 `dist(u,v) <= delta_P(u)+c(P)+delta_P(v)`，从而保存单标量 `max_u {D(B,u)-delta_P(u)}` 即可得到目标根下界。

## 2. 四个实现

| test | profile 与使用范围 | 额外代价 |
| --- | --- | --- |
| Test133 | root-star 与锚路径端点两个 hub；只用于最高 D 层和最终 A 层 | 每询问 2 次 SSSP，逐候选最多读 2 个锥 |
| Test134 | 压缩锚树的全部顶点作为 hub；只用于最高 D/A 层 | 每个 hub 一次 SSSP，逐候选扫描全部 hub |
| Test135 | 单个锚路径标量锥；只用于最高 D/A 层 | 不新增 SSSP，每行一个标量 |
| Test136 | Test135 的路径标量扩展到全部 D/A 层；剩余集合对所有最大可用子集 profile 取最大 | 每行一个标量，另做 subset profile 聚合 |

Test133 的锥最初放在 tour 下界之后，随后移入 cheap heuristic，使其可以在计算 tour 前直接拒绝；最终数据均来自调整后的版本。Test134 用更多 hub 检查“profile 太粗”还是“profile 读取本身不划算”。Test135--136 则检查已支付锚路径能否以常数 profile 避免额外 SSSP 和多 hub 扫描。

## 3. 正确性门禁

全部二进制使用 Release/O2，与 DPBF 在 `1e-6` 内逐例对拍：Test133 宽随机 `200/200`、固定 g15 `100/100`，调整读取顺序后再做 `100/100`；Test134 固定随机 `100/100`；Test135 与 Test136 各 `200/200`。对应 seeds 为 `717571--717576`。这些结果支持实现与上述下界定理一致，但不构成性能正证据。

## 4. 多询问性能门禁

统一基线为同机 Test121。固定 fast20 覆盖五个数据版本和 `g=9..12`，每个组合执行预先固定的第一条询问；它用于跨库快速否决，不用于估计真实 DBLP g13 的总体分布。

| test | fast20 wall | 相对 `8.092850s` | 主要状态变化 |
| --- | ---: | ---: | --- |
| Test133 | `8.307651s` | `+2.65%` | 最高 D values `-3.76%`，最终 A values `-13.13%` |
| Test135 | `8.176690s` | `+1.04%` | 最高 D values `-0.14%`，最终 A values `-1.13%` |
| Test136 | `8.385533s` | `+3.62%` | 全部 D values `-0.03%`，全部 A values `-0.79%` |

Test133 另跑固定 Toronto g13 q1--q5 配对面板：基线合计 `48.265815s`，候选合计 `49.250918s`，回退 `2.04%`；D6 values 合计下降 `1.89%`，A5 values 下降 `7.57%`。Test134 在同一五询问面板把 D6/A5 values 分别减少 `8.02%/9.66%`，但总 wall 增至 `53.927659s`，回退 `11.73%`。更多 hub 确实增强剪枝，却更明确地失败于构造与读取成本。

Test136 虽把路径锥推广到所有层，D2/D3 values 完全不变，D4--D6 合计仅少 `658` 个值；A1--A5 合计只从 `1,192,600` 降到 `1,183,142`。这不是某一条询问的计时异常，而是 20 条固定组合汇总后仍缺少状态级收益。它没有通过短门，因此没有运行 Toronto g13 q1--q5，更没有启动 DBLP g13/g15 长跑。

## 5. 结论

rooted-row 度量锥是**正确且保留同一行根相关性**的批量下界，这一理论结论可复用；但当前逐候选读取方式没有改变 D2--D4 主项。单路径标量过粗，多 hub 又把省下的 tour/传播工作换成 SSSP、profile 构造和 hub 扫描。后续若继续使用该定理，应让 profile 直接跳过一段离线有序归并，或用于消除某类状态维度，而不是再为每个候选叠加常数个启发式比较。
