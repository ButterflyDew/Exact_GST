# Test137：提前 A1 的 anchor-aware 精确 future

更新时间：2026-07-16。Test137 在 Test121 的 permanent-anchor A 框架中，把最低层锚定状态 `A({i},v)` 提前到普通 D 之前生成，并作为所有普通状态的 future 下界。它不改变 D/A 状态语义、root-irreducible branch、离线有序行、facility upper 或 completion，不使用 Hash、数据集、固定 `g`、层号阈值、密度和 wall-time 特判。机制在 fast20 与 Toronto g13 q1--q5 上显著缩小 D，但在预先固定的 DBLP g15 压力询问上被现有 directed-cut 几乎完全覆盖；q33 D3 的时间和空间均回退，因此实现与编译目标已撤回，正确性定理和跨询问证据保留在本文。

## 1. 下界定理

设永久锚组为 `a`，普通状态 `D(S,v)` 尚未覆盖的非锚组为 `R`。任何通过该状态完成的锚定余树都以 `v` 为接口，覆盖 `a` 与全部 `R`。对任意 `i in R`，令

`A_i(v) = A({i},v)`，

即连接锚组、组 `i` 和根 `v` 的最小树。完整余树本身是 `A_i(v)` 的一个可行解，所以

`max_{i in R} A_i(v)`

是普通状态未来代价的合法下界。`A_i` 由同根种子 `d_a(u)+d_i(u)` 做一次全图最短路闭包得到，因而是 exact rooted row，并满足边一致性 `A_i(v)<=w(v,x)+A_i(x)`；若每个 `A_i` 一致，逐点最大值仍一致。因此该下界可以安全进入 Test107 的 A* key、seed 拒绝、relax 拒绝和队列停止。

它还严格支配原 farthest bound。对每个 `i`，任何连接 `a、i、v` 的树至少包含从 `v` 到锚组和组 `i` 的路径，所以

`A_i(v) >= max{d_a(v),d_i(v)}`。

对剩余组取最大后，得到的值不小于原来的 `max{d_a(v), max_i d_i(v)}`。Test137 仍与 directed-cut 和 group-tour 取最大，没有删除原下界。

## 2. 单次生成与正式 A1 复用

第一版只为探测信号额外生成一套 dense A1，D 阶段使用后又按原流程重算正式 A1。fast20 已在这种不利实现下把普通 D values/pops 分别减少 `47.28%/48.17%`，总 wall 仍小降，说明信号来自状态而不是代码常数。

最终实验版消除了重复操作：

1. `A1` 只依赖 `A0` 与 singleton `D1`，因此在 D2 前完整生成 exact rows；
2. D2 及更高普通层读取 `max A1` future；
3. 全部 D 完成后，A 阶段不再执行 A1 heap closure，而按当时更强的 incumbent 和原 future 重新筛选同一批 exact values；
4. 对幸存 A1 roots 补做原 `A+D+D` completion，再按 sparse/dense/ranked-bitmap 的精确字节规则存成正式 A1；
5. A2 及以上继续读取这些正式行，后续流式 A 层完全不变。

早期 dense row 是正式 A1 的超集。重新筛掉 `A1(v)+H(v)>best` 的根安全；补做 completion 恢复了 D 尚未生成时不可执行的完成式。因此该调度没有把预处理结果和正式状态算两次，也不遗漏原 A lattice 的消费者。

## 3. 正确性门禁

全部构建使用 Release/O2，与 DPBF 在 `1e-6` 内逐例一致：只读/重复 A1 原型通过宽随机 `200/200`（seed `717601`）；正式复用版通过宽范围 `g=2..13` 的 `300/300`（seed `717602`）和固定 g15 的 `100/100`（seed `717603`）。Toronto g13 q1--q5 的五个最终权重也与同机 Test121 逐条一致。

## 5. DBLP g15 跨询问否决

大图门沿用 Test116 预先固定的压力编号，不使用 q1。先配对运行 q2 与 q14 的 D2 截止探针：两条的 values、branches 和 pops **逐字段完全不变**，wall 分别从 `129.572s/121.881s` 增至 `162.907s/149.156s`，回退 `25.73%/22.38%`；query peak 各增加约 `267MiB`。

目标重询问 q33 使用已固化的 Test121 D3 快照作控制，并分别运行 Test137 D2/D3 自然边界。D2 只有很小变化：values `153,152,104 -> 151,260,512`（`-1.24%`），pops `245,966,825 -> 243,421,455`（`-1.03%`），层时间 `390.357s -> 401.341s`（`+2.81%`）。进入 D3 后相对收益略增，但仍远低于 8,000 秒目标所需幅度：

| q33 D3 指标 | Test121 | Test137 | 变化 |
| --- | ---: | ---: | ---: |
| values | `316,628,561` | `307,307,579` | `-2.94%` |
| branches | `310,056,931` | `300,784,714` | `-2.99%` |
| pops | `478,661,574` | `467,244,587` | `-2.39%` |

q33 的 anchor-pair 值确实比原 farthest 更常成为 cheap heuristic 来源，但大多数增量不足以越过 incumbent，且 dense A1 的时间/空间不能由约 `3%` 的 D3 row 削减偿还。该门失败后没有运行 q25、D4、A 阶段或完整 q33。

## 6. 结论与后续边界

**可保留结论：**提前 exact A1 是严格 anchor-aware、无参数、无 Hash 的一致 future，并可与正式 A1 单次复用；它在某些图上能让普通 D 状态随层级增加而持续收缩。

**否决结论：**单个“锚组 + 一个剩余组”子问题仍不足以刻画 DBLP g15 的多组共享，现有 directed-cut 已覆盖其大部分强度。下一候选若沿同一思路推进，必须以可摊销接口表达至少两个剩余组与锚主干的联合相关性，或直接消除一类高层状态；不能简单提前物化完整 A2/A3 lattice，也不能保留只对 Toronto 有利的数据集开关。
