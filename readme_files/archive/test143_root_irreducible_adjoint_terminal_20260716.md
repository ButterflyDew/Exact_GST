# Test143：root-irreducible 伴随终端（已撤回）

Test143 尝试把 Test142 的高层终端 `G_T=D(L)+D(R)` 改写为“较小一侧只读取 root-irreducible branch，另一侧作为 accumulator”，并在完整 D 行相交与 branch 相交之间按可精确计算的扫描工作量选择。方法保持精确，宽范围与固定 g15 随机门均通过。

结构计数有正信号：fast20 的终端 checks 从约 `36.02M` 降到 `29.90M`；DBLP g13 q5 从 `13.074M` 降到 `9.145M`；Toronto g15 q1--q5 从 `6.383B` 降到 `4.883B`，约 `23.5%`。但是 Toronto 的伴随时间为 `203.798s`，与 Test142 的 `203.541s` 持平，原因是 branch 方案仍执行约 `13.62B` 次底层扫描工作；fast20 的反向 pops 还从约 `371k` 增至 `444k`。

随后测试的平衡定向与按精确扫描量混合均未改善 fast 面板。该方向只减少了表面 join checks，没有跨目标共享 D 值，也没有改变主要扫描量，因此不再作为活动候选。源码、统计字段、构建目标和 snapshot 方法别名已撤出；有效负结果保留在本文，历史结果目录仅作证据，不代表当前实现。
