# Test147：按工作量惰性构建 dual-cut（已否决）

更新日期：2026-07-17。Test147 是一次只在 Test 分支验证的无参数调度实验，未进入 Test145、Test146 或任何 release。

## 动机与规则

五数据集 g15 D2 全量统计显示，MovieLens 的普通状态很少，但 eager dual-cut 在 40 个询问中累计耗时约 562.5 秒，占该数据集 D2 总墙钟约 76%。no-dual 消融在冻结五问上把 D2 总时间从 92.417 秒降到 47.969 秒，但 D2 状态由 119--31,675 增至 24,247--130,659，说明 dual 有效，只是前置成本与轻询问不匹配。

Test147 沿用 residual packing 的精确工作量思想。dual 的购买成本记为 `g(2m+n)`；尚未构建 dual 时，只累计可能被更强下界减少的普通队列弹出与边松弛。累计租金达到购买成本后构建 dual；若发生在 D2 内，则从完成的下一条 pair 行开始使用。规则没有数据集、固定 g、层号、密度、时间或经验常数特判。

## MovieLens 冻结五问

所有计时均为 Release/O2，查询顺序为原始 q5、q33、q17、q22、q12。

| 方法 | D2 总时间 | D3 总时间 |
| --- | ---: | ---: |
| Test145 eager dual | 92.417s | 96.570s |
| no-dual 消融 | 47.969s | 未继续 |

Test147 在 q5 的第 85/91 条 pair 行后才达到预算，dual 构建耗时 12.680 秒。其余四问在 D2 结束时仍未构建。进入 D3 后，未提前构建的询问先发生状态膨胀，达到预算时已经无法收回本层代价。

## 结论

**否决 Test147。** dual 的收益具有跨层前置性：当前层已经发生的工作不能可靠预测“不构建 dual 会给下一层增加多少状态”。该调度虽满足无参数要求，但信号系统性滞后，D3 总时间比 eager dual 慢约 85%。因此启用代码和构建目标已撤出，仅保留 no-dual 探针与结果快照，供后续研究更便宜的 dual 构造或可在 D2 前计算的结构性必要条件。

本实验没有引入新的论文引用；dual-cut、Dreyfus--Wagner 状态和当前主线的文献边界仍以 Test145 文档为准。
