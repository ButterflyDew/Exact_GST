# Test94：D/A 相位边界的 Dual 重筛（已否决）

更新时间：2026-07-15。Test94 在 Test90 的普通 D 阶段全部结束、锚定 A 阶段尚未开始时，对已存普通 row 做一次 directed-cut 重筛。该改动已完整撤回，当前 Test80 仍是 Test90。

## 1. 方法与正确性

普通状态 `D(S,v)` 生成时已用当时的可行上界剪枝，但之后的 early upper 和流式 A0 completion 可能继续降低 `best`。在 D/A 的唯一相位边界，Test94 对每个已存值重新计算 Test87 的 directed-cut 下界 `C(v,G\\S)`；若

```text
D(S,v) + C(v,G\\S) > best,
```

则任何经该状态完成的全解都不可能改善当前可行上界，可以永久删除。保留项按原 dense/sparse 判据重建顶点、距离和 branch 位图。严格大于保证等于 `best` 的状态不被删除。

该过程没有经验阈值，只扫描一次；不建 Hash，不改变状态定义。最坏增加与普通 row payload 线性的扫描和单 row 临时空间，渐进阶不超过原状态物化上界。机制依赖 Test80 的 directed-cut 证书，而不是图或查询压缩。
