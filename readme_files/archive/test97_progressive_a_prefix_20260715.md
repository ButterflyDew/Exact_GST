# Test97：One-Third A 前缀调度

更新时间：2026-07-15。Test97 检查一个不改变 Test80 状态定义的调度问题：能否在普通状态尚未全部完成时提前计算一段锚点状态 A，用较早的完整树上界削减后续高层 D。原型通过正确性门禁，但跨库收益不稳定、A 状态与峰值空间增加，因此已完整撤回；当前 Test80 仍为 Test90。

## 1. 依赖边界

令非锚点组数为 `k=g-1`，普通状态最大层为 `h=floor(g/2)`，并令

```text
q = ceil(k/3).
```

`A(S,v)` 的生成只读取更小的 A 子集和满足 `X subset S` 的普通行 `D(X,v)`。因此，完成 `D_1,...,D_q` 后，已经可以精确生成 `A_1,...,A_q`，不需要 `D_{q+1},...,D_h`。

此时 `k-q<=2q`，所以至少存在把剩余组分成两个大小不超过 q 的普通块的平衡划分。由此，`A_q+D_{<=q}+D_{<=q}` 已能构造合法完整树，并把所得可行上界反馈给尚未执行的高层 D。这个边界只由状态依赖和块容量推出，不读取数据集、固定 g、row 密度或运行时间。

## 2. 原型流程与正确性

原型把原普通层循环封装为单层过程，并按以下顺序执行：

1. 生成 `D_1,...,D_q`；
2. 仍用原离线有序列表 recurrence 和原图闭包生成 `A_1,...,A_q`；
3. 对当前已经可用的 D 划分立即执行 completion，只把真实可行树写入 `best`；
4. 使用新 `best` 生成 `D_{q+1},...,D_h`；
5. 全部 D 就绪后，对提前保存的 A rows 补扫 completion，以恢复早期尚不可用的高层 D 划分；
6. 继续原 Test84 顶层 A 流式消费者。

早期 A 的 recurrence 依赖已经全部就绪；早期 completion 只产生可行上界；补扫又恢复了原候选集合。较松上界下生成的 A row 至多保留额外值，不会缺失原调度需要的值。因此原型不改变答案语义，也不引入 Hash、近似剪枝或经验参数。

为不额外改变“最终 A 层不持久化”的表示规则，实验只在 `q<=h-2` 时启用该前缀；其余 g 完全保持 Test90 顺序。这是原型的状态生命周期边界，不是按固定 g 选择。

## 3. Release/O2 证据

正确性门禁均与 DPBF 在 `1e-6` 内一致：宽范围随机图 `200/200`（seed `715701`），固定 g13 随机图 `50/50`（seed `715702`）。撤回并重建 Test90 后，固定 g13 再次通过 `50/50`（seed `715703`）。

fast20 的总 query time 从 Test90 的 `8.261585s` 降到 `8.133s`，但结果明显不稳定。以 g12 为例：

| 数据版本 | Test90 total | Test97 total | D values | A values | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| Toronto | `1.041s` | `0.999s` | `378,629 -> 375,378` | `197,111 -> 195,714` | 小幅正向 |
| Toronto-new | `1.917s` | `1.972s` | `860,605 -> 716,696` | `556,324 -> 579,332` | D 收缩仍被 A 与 completion 成本覆盖 |
| DBLP | `0.166s` | `0.147s` | `50,267 -> 47,544` | `26,693 -> 27,517` | 很小，且打印精度下 incumbent 未变化 |
| DBLP-new | `0.196s` | `0.190s` | `86,957 -> 81,385` | `31,355 -> 40,858` | A 明显膨胀 |

Toronto g13 使用同一 Test90 基线的三次 `total_ms` 为 `8079/8048/8058ms`，Test97 为 `8016ms`，只改善约 `0.4%--0.8%`。普通 values 从 `2,703,962` 降到 `2,571,569`，但锚点 values 从 `493,596` 增到 `752,813`；D5/D6 values 从 `347,048/198,478` 降到 `266,532/146,601`，peak RSS 却从约 `57.5--57.6MiB` 升到 `59.1MiB`。

这说明机制确实能把 A4 得到的上界前移到 D5/D6 之前，但也必须在较松 incumbent 下先支付整段 A1--A4，并让这些 rows 与后续 D 同时驻留。它主要是在两个既有精确阶段之间搬移工作，没有消除状态维度；收益取决于“高层 D 被删多少”和“早期 A 多生成多少”的实例差异。

## 4. 结论

Test97 不满足继续进入 DBLP g13 q5 的门槛，更没有运行 q1。它给出的可复用结论是：

- `q=ceil((g-1)/3)` 是完整 A 前缀首次能够产生三块可行上界的严格依赖边界；
- 完整提前物化 A 前缀会把高层 D 工作换成更多 A 工作与更长 row 生命周期，不能形成稳定的时空复杂度改进；
- 后续若利用该边界，必须只计算上界所需的更小接口族，或从状态表示上共享早期 A 与正式 A，而不能再次提前运行完整 A lattice。
