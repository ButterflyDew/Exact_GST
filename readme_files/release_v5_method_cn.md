# 方法：永久锚点有序状态与伴随高层求值的精确 Group Steiner Tree 搜索

## 1. 问题定义与方法动机

给定一个带非负边权的无向图 `G=(V,E,w)` 和 `g` 个终端组 `T_1,...,T_g`，Group Steiner Tree（GST）要求找到一个最小权连通子图，使其至少包含每个终端组中的一个顶点。不同终端组可以重叠，最优解也可以包含不属于任何终端组的 Steiner 顶点。记 `n=|V|`、`m=|E|`。

经典精确动态规划以“已经覆盖的组集合”和“当前根顶点”为状态：同一根上的两个部分树可以合并，合并后的根再沿图边移动。这个框架是完备的，但在大图上有三个主要成本。第一，组子集与根顶点形成指数级状态行；第二，同一批普通部分树会被多个锚定目标重复读取；第三，较好的完整解通常在后期才出现，使早期图闭包保留过多根状态。

本文方法围绕一个**永久锚点组**重新组织状态空间。锚点之外的部分树先作为普通分支离线生成；包含锚点的部分树沿唯一锚定侧吸收这些分支。锚定格的低层仍正向计算，而高层不再物化正向状态，改为从完整解终端反向求值。为了使反向求值可执行，方法进一步利用 directed-cut 势函数的组可加性，把原本按目标重复生成的终端候选转置成按根共享的一次扫描。

## 2. 方法概览

选择一个终端组 `T_a` 作为永久锚点，令 `K={1,...,g}\{a}`、`k=|K|=g-1`，并令 `h=floor(g/2)`。方法维护三类正向状态或存储行，并用一个不单独物化的中间量说明反向语义：

```text
D(S,v): 连接 S subseteq K，并以 v 为根的最小普通树；
A(S,v): 连接锚点组 T_a 与 S subseteq K，并以 v 为根的最小锚定树；
F(S,v): 已得到闭包后 A(S,v) 时，从同一根继续的原始后缀成本；
H(S,v): H(S)=C(F(S))，即把 F 经最短路闭包拉回到进入 S 的合并根。
```

普通状态生成到 `|S|<=h`。完整正向锚定格只需要生成到 `a_max=h-1`；本文在 `c=floor(a_max/2)` 处做结构性切分，只正向物化 `|S|<=c` 的 `A`，并用 `H` 等价替代 `c<|S|<=a_max` 的高层 `A`。切分只由锚定格深度决定，不依赖数据集、固定 `g`、状态密度或运行时间。

一次查询依次执行以下阶段：

1. 计算各组到全图的距离，建立初始完整解上界并选择永久锚点；
2. 构造组间路径下界、边容量势下界和围绕锚主干的可行解上界；
3. 按子集大小递增生成普通状态 `D`，同时利用已经完成的小块状态收紧上下界；
4. 按子集大小递增生成切分以下的低层 `A`，每完成一行立即尝试完整解结算；
5. 按根扫描 ordinary 状态，一次生成所有高层目标需要的终端事件；
6. 按子集大小递减生成高层 `H`，并在每行完成后与低层 `A` 的切分边界相交；
7. 当所有高层依赖和边界都已结算时返回精确最优值。

这里没有备用框架或运行时回退。第 4 阶段到第 6 阶段的变化只是对同一锚定依赖图改变求值方向。

## 3. 组距离、锚点与初始可行解

### 3.1 组距离

对每个终端组 `T_i` 执行一次多源最短路，得到

```text
d_i(v) = min(t in T_i) dist_G(v,t).
```

这些距离既用于构造可行解，也用于后续下界。若所有组无法处于同一连通分量，则查询无解。

### 3.2 共同根上界与锚点选择

对任意顶点 `r`，分别沿最短路把 `r` 接到每个组可得到一个合法连通方案，其成本不超过

```text
U_star(r) = sum(i=1..g) d_i(r).
```

方法选择 `r_star=argmin_r U_star(r)`，并以 `B=U_star(r_star)` 初始化当前最优完整解上界。随后选择在 `r_star` 上距离最远的组为锚点：

```text
a = argmax_i d_i(r_star).
```

直观上，最远组需要最长的根向路径，把它固定为锚主干有机会让更多普通分支共享这段已付费路径。锚点一旦确定便保持不变。

## 4. 统一剩余成本下界

设一棵部分树当前覆盖组集合 `C`、根为 `v`、已付成本为 `x`，尚未覆盖的组为 `R`。若能给出不超过任何真实完成成本的下界 `L(v,R)`，则只有满足

```text
x + L(v,R) <= B
```

的状态才有可能改进当前完整解。本文取三个合法下界的最大值。

### 4.1 最远组下界

任何完成树都必须从当前根接到每个剩余组，因此至少要支付其中最远的一项：

```text
L_far(v,R) = max(i in R) d_i(v).
```

### 4.2 组间路径下界

定义组间距离 `delta(i,j)=min_{u in T_i,v in T_j} dist_G(u,v)`。在该度量上用子集动态规划计算经过剩余组的最短 Hamiltonian path。任意连接这些组的树在边加倍后可以形成覆盖所有命中组的游走，因此其一半给出合法下界：

```text
L_tour(v,R)
= 1/2 * min(i,j in R) [d_i(v) + HP(R,i,j) + d_j(v)].
```

该下界捕获组之间不能任意靠近的全局结构，但不显式区分多组路径在原图上共享边的情况。

### 4.3 边容量势下界

为了处理共享边，方法把每条无向边 `{u,v}` 暂时看作两个记账方向 `(u,v)` 和 `(v,u)`。这只是下界证明中的记账方式，不会把输入图改成有向图，也不会让可行解重复支付边权。

对每个组 `i` 构造顶点势函数 `pi_i(v)`，要求终端处 `pi_i(t)=0`，并对每条有向记账弧满足

```text
sum_i max(0, pi_i(u)-pi_i(v)) <= w(u,v).
```

可以把 `max(0,pi_i(u)-pi_i(v))` 理解为组 `i` 沿该方向使用这条边时向边收取的费用。约束保证所有组在同一方向上的总收费不超过一次边权。即使多个组共享同一条树边，把各组势相加也不会重复计算这条边。

现在考虑一棵以 `x` 为根并连接剩余组 `R` 的任意树。对每个组选择树中一条从 `x` 到该组终端的路径。沿路径累加势下降，至少得到 `pi_i(x)`；再按树边汇总所有组的收费，每条边由容量约束最多贡献一次边权。因此

```text
L_cut(x,R) = sum(i in R) pi_i(x)
```

不超过真实完成树成本。

势函数按顺序分配边容量。令 `res(u,v)` 为尚未分配的有向容量，初始为 `w(u,v)`。处理组 `i` 时，在残量图上计算到 `T_i` 的最短距离 `q_i(v)`，并在共同根处截断：

```text
C_i = q_i(r_star),
pi_i(v) = min(q_i(v), C_i).
```

随后从每条弧残量中扣除正势差。由于每一步只使用尚未分配的容量，最终所有组势自然满足总容量约束。

### 4.4 只从改写弧启动残量闭包

第一个组可以直接使用原始组距离。后继组虽然仍需在残量图上求最短路，但不必在初始化时检查全部有向弧。原始组距离满足

```text
d_i(u) <= w(u,v) + d_i(v).
```

若某条弧的残量从未被前面势函数降低，则 `res(u,v)=w(u,v)`，上式已经证明它不可能使当前距离下降。因而只需检查此前被势函数改写过的弧，把其中真正违反残量三角不等式的端点放入优先队列；随后仍在完整残量图上执行 Dijkstra。

这一步只删除可证明无效的初始化检查。未改写弧仍可能出现在从违反点继续传播的路径中，因此图闭包阶段不能删去它们。由原始三角不等式和完整后续传播可知，所得残量最短距离、截断势和最终下界与全弧初始化逐点相同。

### 4.5 统一剪枝函数

最终使用

```text
L(v,R) = max(L_far(v,R), L_tour(v,R), L_cut(v,R)).
```

三个分量均为合法下界，其最大值仍然合法。该函数在同根合并候选进入队列前和沿图边松弛前都会被检查；优先队列按 `x+L(v,R)` 排序。当队首已经大于 `B` 时，余下条目都不可能改善完整解。

## 5. 锚主干上的共享上界

共同根星形方案没有充分利用组之间的路径共享。方法从 `r_star` 到锚点组恢复一条最短路径 `P`，并以 `P` 为多源计算全图到主干的距离。对若干小组块寻找“这些组先汇合，再接入 `P`”的候选汇合点，把候选点到主干的最短路父路径取并集并压缩二度路径，得到一棵较小的候选锚树。

在该树上执行子集动态规划：一个普通组块可以在某个树节点本地接入，也可以交给某个子树，并在确实使用子树时支付一次树边成本。所得结构由原图中的真实最短路组成，因此一定是一棵合法完整解，只能安全降低 `B`。候选树没有覆盖最优拓扑时只会使上界较松，不影响精确性。

锚树动态规划不是每完成一层 ordinary 状态就无条件重算。一次树 DP 的循环工作由非锚组数和压缩树节点数精确确定；只有此前 ordinary 图闭包实际发生的 queue pop 与 edge relaxation 足以支付这份工作时才执行。更紧上界无法事后省去已经完成的同根 merge 枚举，所以 merge 工作不计入预算。该调度只决定何时购买一个合法上界，不改变主状态或终止条件。

## 6. 普通状态 `D`

### 6.1 状态行与图闭包

对固定组集合 `S`，所有根上的 `D(S,v)` 构成一张状态行。若 `M_S(u)` 是在根 `u` 上把若干较小普通树合并得到的种子成本，则

```text
D(S,v) = min_u [M_S(u) + dist_G(u,v)].
```

因此每张状态行分为两个步骤：先离线生成同根种子，再执行一次多源图闭包。状态按 `|S|` 递增生成，所以任何种子只依赖已经完成的较小状态行。

### 6.2 不可拆分普通分支

标准递推会枚举 `S` 的所有非空真子集，并在同一根相加。问题在于，某个已经完成的 `D(Q,v)` 可能在根 `v` 上仍等于更小部分的直接合并；若把它作为一个整体交给多个后继，后继会重复消费同一分解。

方法固定 `S` 中编号最小的组为枢轴 `p(S)`。累计侧始终包含枢轴，另一侧作为待接入分支。定义 `Br(Q,v)`：单组集合总是合法分支；多组集合只有在图闭包后的 `D(Q,v)` 严格优于同根直接拆分值时才发布。递推写为

```text
M_S(v) = min(empty != Q subseteq S\{p(S)})
         [D(S-Q,v) + Br(Q,v)].
```

若 `D(Q,v)` 仍可在根上拆分，就继续展开它；子集大小每次严格下降，最终得到单组或不可继续拆分的分支。固定枢轴所在部分为累计侧并依次吸收其余分支，可以重建任意标准同根分解，因此该接口消除的是等价重复而不是合法解。

### 6.3 有序状态行

状态行只保存通过上下界检查的有限根值，并按顶点编号有序。根据实际所需字节，一张行可使用递增稀疏列表、稠密数组或带 rank 的位图。两张行的共同根通过线性归并、二分查找或位图交集获得；选择依据是实际数组长度和精确探测数，不使用 Hash 或经验密度阈值。

## 7. 普通阶段中的界增强

普通状态完成到一定块大小后，会自然获得新的真实部分树和已经发生的搜索工作。方法利用这些信息加强界，但不改变任何 `D/A/H` 状态。

### 7.1 三块和四块可行解

令 `q_3=ceil(k/3)`、`q_4=ceil(k/4)`。当所有大小不超过 `q_3` 的普通行可用时，非锚组全集可以分成三个大小不超过 `q_3` 的块。把三张 `D` 树与锚点最短路接到同一根即可得到真实完整解。类似地，在 `q_4<q_3` 时，四块信息更早可用，可先构造四块上界。

这些分块大小来自“覆盖全部 `k` 个非锚组所需的最大块大小”，不是对某个固定 `g` 的特判。候选一旦改善 `B`，同层尚未开始的状态行和所有后续阶段立即使用新上界。方法还可对当前最佳分块执行有限个精确图闭包，使锚侧与一个普通块先共享路径，再与其余块汇合；这些临时行只用于构造可行解，不进入正式状态递推。

### 7.2 剩余容量打包

初始边容量势分配后，部分弧仍有未使用残量。丢弃这些容量不会影响正确性，但会浪费可用于证明更强下界的边费用。方法在现有势函数之外为各组构造新的候选势 `q_i`，并为每个组选择缩放系数 `0<=lambda_i<=1`。所有活跃组同步增加相同步长，步长由两类约束共同决定：任何 `lambda_i` 不能超过 1，任何弧上新增正势差总和不能超过该弧剩余容量。

形式化地，若活跃组在弧 `(u,v)` 上的单位负载为

```text
load(u,v) = sum(i active) max(0,q_i(u)-q_i(v)),
```

则本轮最大安全步长为

```text
Delta = min(
    min(i active) [1-lambda_i],
    min((u,v): load(u,v)>0) residual(u,v)/load(u,v)
).
```

更新 `lambda_i+=Delta` 并扣除相应残量后，达到完整尺度的组或被饱和弧阻塞的组停止。每轮至少固定一个组或一批使用饱和弧的组，因此过程有限终止。最终把 `lambda_i q_i` 加到旧势函数上；旧收费加新增收费仍不超过每条弧的原始边权，所以加强后的 `L_cut` 仍然合法。

打包需要额外的图级最短路和弧扫描，不能在轻查询上无条件执行。方法从第一批真正执行图闭包的二组 ordinary 行开始累计实际 seed、queue 和 edge-scan 工作；只有累计工作覆盖打包的结构成本、且后面仍有 ordinary 行可以受益时才执行一次。打包完成后立即释放残量结构。该条件只决定是否购买更强下界；未购买时主算法仍使用初始合法势，答案不变。

## 8. 低层锚定状态 `A`

锚定状态以锚组距离为起点：

```text
A(empty,v) = d_a(v).
```

对非空 `S`，锚定侧吸收一个 ordinary 分支 `Q`，再执行图闭包：

```text
A(S) = Closure(
    min(empty != Q subseteq S) [A(S-Q) + Br(Q)]
).
```

每次转移只有一侧含锚点，所以不会产生两个彼此竞争的锚定主干。低层 `A(S)` 完成后，令剩余组为 `K-S`，枚举其无序二分 `L union R=K-S` 并结算

```text
A(S,v) + D(L,v) + D(R,v).
```

空 ordinary 块成本定义为零。三个部分在根 `v` 相交，因此它们的并是合法完整解。行最小值先用于分割级拒绝，随后才做有序共同根扫描；这只减少读取，不改变分割集合。

## 9. 高层锚定格的伴随求值

### 9.1 把正向递推看作算子 DAG

定义图闭包算子

```text
C(f)(v) = min_u [f(u)+dist_G(u,v)].
```

吸收 ordinary block `Q` 的正向转移是 `T_Q(f)=C(f+Br(Q))`。在 min-plus 内积

```text
<f,g> = min_v [f(v)+g(v)]
```

下，无向图距离对称，因此闭包自伴随：`<C(f),g>=<f,C(g)>`。由此，正向转移的伴随为

```text
T_Q*(g) = Br(Q) + C(g).
```

完整高层 `A` 计算可以看作一个以组 mask 为节点的有向无环图：边表示吸收一个 ordinary block，每个节点还有一个 `A+D+D` 完成终端。伴随求值从这些终端出发，沿全部依赖边反向传播。

### 9.2 反向状态

对高层 mask `T`，定义 `F_T` 为已经得到闭包后 `A_T` 时的同根原始后缀，并定义实际保存的 `H_T=C(F_T)`。若 `G_T` 是 `T` 处的直接完成终端，则

```text
F_T = min(
    G_T,
    min(U strict-superset T) [Br(U-T) + H_U]
),
H_T = C(F_T).
```

源码先把 `F_T` 候选写入工作数组，再执行一次 Dijkstra 闭包并保存为 `H_T`。高层 mask 按大小递减处理，因此所有 `H_U` 在计算 `F_T` 前已完成。枚举覆盖所有 strict-superset 依赖，包括一次加入多个组并直接跨过平衡切分的边；只反向传播 singleton 或相邻层会漏解，因此不允许这样简化。

### 9.3 第一条跨切分边

任意完整正向推导要么在低层 `A` 直接结束，要么存在唯一一条从低层 `S` 首次进入高层 `T` 的边。该边之前的成本由已物化的 `A(S)` 给出；进入 `T` 的闭包及其后全部成本由 `H_T=C(F_T)` 给出，因此跨切分候选为

```text
A(S,v) + Br(T-S,v) + H_T(v).
```

每张 `H_T` 完成后立即结算所有可能的低层 `S`。这样得到的每条反向推导都对应一条原正向路径；反过来，每条原高层路径也有唯一第一条跨切分边。因而低层直接终端加全部跨切分候选与完整正向锚定格等价。

### 9.4 锚定前缀下界

反向行 `H_T(v)` 描述的是从进入 `T` 的合并根 `v` 经闭包并继续完成还需支付多少，剪枝时还必须知道任何具体正向前缀到这里至少已经付了多少。方法对锚点加 `T` 使用与普通阶段对称的前缀下界：到这些已纳入组的最远距离、组间路径下界和 directed-cut 势之和的最大值。若

```text
anchored_prefix_lower(T,v) + H_T(v) > B,
```

则任何经过 `(T,v)` 的完整推导都不能改善上界，可以删除该反向值。该下界在一张 `H` 的闭包期间保持不变，并满足沿边的一致性。

## 10. 按根转置生成高层终端

### 10.1 重复来源

高层 `H_T` 的直接终端是

```text
G_T(v) = min D(L,v)+D(R,v),
```

其中 `L`、`R`、`T` 两两不交并覆盖 `K`。若逐个目标 `T` 枚举 `K-T` 的二分，同一根上的同一 ordinary 值会被大量目标重复读取。

### 10.2 directed-cut 约化恒等式

记组集合 `X` 在根 `v` 的势为 `pi_X(v)=sum_{i in X} pi_i(v)`。对合法分割 `L union R union T=K`，有

```text
D(L,v)+D(R,v)+pi_(a union T)(v)
= [D(L,v)-pi_L(v)]
  + [D(R,v)-pi_R(v)]
  + pi_(a union K)(v).
```

定义

```text
r(S,v) = D(S,v)-pi_S(v),
beta(v) = B-pi_(a union K)(v).
```

则一个二块终端只有在 `r(L,v)+r(R,v)<=beta(v)` 时才可能改善当前上界。原来随目标 `T` 变化的 directed-cut 检查被转成了固定根上的统一预算。

### 10.3 流式按根聚合

方法按一小批连续根顶点顺序读取所有普通行。对固定根 `v`，收集当前存在的 `(S,D(S,v))`，计算约化值并排序。满足预算的单块或不相交二块直接确定目标 `T=K-(L union R)`，并只保留同一 `<T,v>` 的最小真实成本。聚合后再执行完整的锚定前缀下界，剩余候选成为稀疏终端事件。

该过程不建立 Hash，也不改变 ordinary 行。终端事件只把原本按目标重复枚举的同一组候选换成按根一次生成。

### 10.4 两条精确枚举路线

对固定根有两条等价路线。第一条按约化值排序，用单调右端点确定满足预算的数值对前缀，再过滤 mask 相交对。第二条对每个现有 `L` 直接枚举 `K-L` 的子掩码 `R`，天然只产生不相交对。

方法在每个根上先计算两条路线将执行的精确探测数并选择较小者。若选择排序路线，其探测数不超过子掩码路线；若选择子掩码路线，则实际执行的正是该探测数。因此无论选择哪条路线，组合枚举都受

```text
sum(L) 2^(k-|L|) <= 3^k
```

约束。该选择没有经验阈值，也不会改变终端集合。

## 11. 正确性

### 11.1 上界与下界安全性

共同根、锚主干、三块和四块候选都由真实图路径与精确部分树组成，所以 `B` 始终是某个合法完整解的成本。最远组、组间路径和边容量势均不超过真实剩余成本；剩余容量打包只使用尚未分配的容量。故所有 `partial+lower>B` 剪枝都安全。

### 11.2 普通递推完备性

任意标准同根分解中的可拆分子树都可以继续展开，直到每个待接入部分是 singleton 或 root-irreducible branch。固定枢轴所在部分为累计侧并依次吸收其他分支，得到本文 ordinary 递推的一条等价序列。因此只发布不可拆分分支不丢失最优普通树。

### 11.3 `A+D+D` 完备性

把最优 GST 中命中锚点组的部分视为唯一锚定侧。树上存在一个平衡结点，使删除该点后每个连通分量包含的终端组数不超过 `h`。把含锚点的分量合并为锚定侧，其余分量合并为至多两个 ordinary 侧，可以得到大小分别不超过 `h-1`、`h`、`h` 的 `A(S)+D(L)+D(R)` 分解。因此完整正向锚定格必有一个 completion 表示全局最优树。

### 11.4 伴随高层等价性

任意进入高层的正向推导都有唯一第一条跨切分边。闭包自伴随使该边之后的算子可以按相反顺序移动到终端一侧而保持 min-plus 内积不变；高层 `H` 又枚举全部原依赖边，所以每条正向高层路径与一条反向路径一一对应。转置终端只是利用势可加性重排枚举并在同一 `<T,v>` 上提前取最小值，不改变终端函数。故低层 `A`、转置终端和高层 `H` 的组合与完整正向 `A` 格等价。

综合以上结论，算法结束时 `B` 既不小于全局最优值，又已由状态空间中的某个完整推导达到全局最优值，因此返回精确答案。

## 12. 复杂度

令 `a_max=h-1`、`c=floor(a_max/2)`，并定义

```text
N_D = sum(i=1..h) C(k,i),
N_A = sum(i=1..c) C(k,i),
N_H = sum(i=c+1..a_max) C(k,i).
```

组距离需要 `O(g(m+n log n))` 时间和 `O(gn)` 空间。组间路径动态规划需要 `O(2^g g^3)` 时间和 `O(2^g g^2)` 空间。势函数构造最坏仍需 `O(g(m+n log n))`；changed-arc 初始化只改善实际扫描量，不改变最坏阶。

ordinary 合并、`A+D+D` completion、转置终端与伴随依赖的组 mask 关系均受 `O(3^k)` 控制。最坏情况下每张状态行包含全部顶点并执行一次图闭包，因此主要时间上界可写为

```text
O(2^g g^3
  + g(m+n log n)
  + 3^k n
  + (N_D+N_A+N_H)(m+n log n)
  + t 3^k),
```

其中 `t` 是压缩锚树节点数。理论上若图闭包采用 Fibonacci heap，单次闭包为 `O(m+n log n)`；具体实现使用二叉优先队列时包含相应对数因子和 stale 条目。

若所有行都稠密，状态空间上界为

```text
O((N_D+N_A+N_H)n + gn + m + E + t2^k),
```

其中 `E` 是转置终端事件数。实际实现只保存通过界检查的有序根值，并在稀疏、稠密和 ranked-bitmap 布局中选择实际字节最少者。伴随切分减少高层正向状态的实际驻留，但不保证所有实例上固定比例的空间下降。

## 13. 与既有工作的关系

本文的 rooted subset recurrence 源自 [Dreyfus and Wagner, 1971](https://doi.org/10.1002/net.3230010302)。[Dijkstra Meets Steiner](https://arxiv.org/abs/1406.0492) 给出以一致 future cost 引导的 goal-oriented 精确 Steiner 搜索；[DS*](https://arxiv.org/abs/2011.04593) 将可用启发式放宽为任意 admissible lower bound。这两项工作求解普通 Steiner tree，但与本文的状态搜索和下界正确性边界直接相关。directed-cut dual-ascent 路线源自 [Wong, 1984](https://doi.org/10.1007/BF02612335)。

GST 的直接 CPU 基线来自 [PrunedDP++](https://doi.org/10.1145/2882903.2915217)。[GPU4GST](https://doi.org/10.1145/3769792) 在 PACMMOD/SIGMOD 2025 提出 concurrent DP、GPU 工作量平衡和相应剪枝，并已公开[代码与数据](https://github.com/toziki/GPU4GST-sigmod)。因此本文不能把“使用 subset DP、future lower bound 或比 PrunedDP++ 快”本身作为新颖性；GPU4GST 也是论文级实验必须直接比较的现有方法。

经典 subset merge、Dijkstra、一般 directed-cut 下界、有序列表、位图和优先队列不属于本文的新贡献。当前仓库的候选组合是：永久锚点下的 `D/A` 状态组织、root-irreducible ordinary 分支、高层锚定 DAG 的伴随求值、利用组势可加性的按根转置终端，以及界增强的精确工作量摊销。现有检索已覆盖精确 GST 主线和邻近精确 Steiner 状态搜索，但这仍不是对所有等价构造的穷尽性新颖性证明；投稿前还需用正式定理和逐项文献矩阵确认边界。性能目标、GPU4GST 对照缺口和论文就绪度见 `release_v5_target_and_publication_gap.md`。
