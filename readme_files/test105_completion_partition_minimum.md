# Test105–107：A+D+D Completion 的分层最小值下界

更新时间：2026-07-15。当前 Test80 研究版保留 Test107，ReleaseV4 保持冻结。Test105、Test106 和 Test107 是同一方法逐层增强的三个单变量版本：Test105 在分块级拒绝，Test106 在共同根级拒绝，Test107 在读取第二个普通分量前再次拒绝。本文把它们统一说明为一条完整主线，避免把三个版本误读成三套算法。

## 1. 问题与核心思路

对一张已经闭包的锚定行 `A(S,·)`，设尚未覆盖的非锚点组为 `U`。原 completion 枚举每个无序分块 `U=L∪R`，并在三张行的共同根上计算

```text
min_v A(S,v) + D(L,v) + D(R,v).
```

Test104 只解决“如何更快找到共同根”：兼容时用三路位图相交，否则使用原有有序列表。它不删除分块，也不删除最终精确代价检查。Test105–107 解决的是另一个问题：**在支付共同根枚举、D 行查找或完整加法之前，能否用已有行的精确最小值证明当前对象不可能改善 `best`。**

记一张当前存储行的最小有限值为

```text
μA(S) = min_v A(S,v),
μD(X) = min_v D(X,v).
```

空 D 侧代价为 0；单组 D 侧是到该组的距离，其全局最小值也是 0。三个版本依次使用下面的下界。

```text
分块级：   μA(S)   + μD(L)   + μD(R)
根级：     A(S,v)  + μD(L)   + μD(R)
分量级：   A(S,v)  + D(L,v)  + μD(R)
```

每向下一层一步，就用一个已经知道的精确值替换对应的全局最小值，所以下界单调增强。某层下界严格大于当前 `best` 时，后续工作立即结束；否则才进入下一层。整个过程没有经验参数，不读取数据集名、`g`、层号、行密度或运行时间，也不引入 Hash。

## 2. 完整执行流程

### 2.1 行摘要的产生

普通 D 行完成后，`StoreOrdinaryRow` 原本就要遍历全部有限值并写入 sparse、dense 或 ranked-bitmap 表示。Test105 在同一循环中顺带维护 `μD(S)`，不做第二次扫描。空行的最小值保持正无穷；单组行不物化，其最小值直接取 0。

锚定 A 行的 Dijkstra 闭包按非降代价结算根。每个有效根进入 `settled` 时，同步更新当前行的 `μA(S)`。A0 的根域是全图顶点，行值为到 anchor group 的距离，因此最小值直接是 0。A 最小值只在当前行生命期内保存，不形成新的状态表。

### 2.2 第一级：分块级结束

`CompleteRoots` 仍按原顺序枚举所有合法无序分块 `(L,R)`。先计算

```text
LB_partition = μA(S)+μD(L)+μD(R).
```

若 `LB_partition>best`，**整个分块结束**，不构造 A-root bitmap、不扫描 D 行，也不进入任何共同根内核。否则继续处理该分块。Test105 到此为止。

### 2.3 第二级：共同根级结束

对 Test105 幸存的分块，Test104 的位图或有序路径开始枚举候选 A 根 `v`。在读取两张 D 行的精确值之前，先计算

```text
LB_root = A(S,v)+μD(L)+μD(R).
```

若 `LB_root>best`，**当前 A 根结束**。位图路径已经支付了 word 相交和置位枚举，但省去两侧 rank/value 解码；有序路径在确认 `v` 属于 A 根集后立即结束，甚至可能省去另一张稀疏 D 行的成员查找。Test106 到此为止。

### 2.4 第三级：普通分量级结束

Test106 幸存后，算法取得第一侧普通分量的精确值。若当前有序回退的 driver 本来就是 `L` 或 `R`，其精确值已经免费随枚举得到，优先使用该值；否则沿旧路径先读取左侧 `D(L,v)`。然后计算相应的增强下界：

```text
A(S,v)+D(L,v)+μD(R),
```

或在右侧是已有 driver 时对称使用

```text
A(S,v)+μD(L)+D(R,v).
```

若增强下界大于 `best`，**当前根的第二侧读取结束**。只有三级下界都不能拒绝时，算法才读取剩余 D 值，并执行原来的精确候选更新。位图路径采用固定的左侧优先顺序；有序路径优先复用已有 driver，不根据数据集或运行统计换序。

### 2.5 总流程与结束条件

```text
生成 D rows，并在原序列化循环中保存 μD
                         |
闭包一张 A row，并在 settled roots 上得到 μA
                         |
枚举合法无序分块 U=L∪R
                         |
μA+μD(L)+μD(R) > best ? ----是----> 结束整个分块
                         |
                        否
                         |
用位图或有序列表枚举一个 A 根 v
                         |
A(v)+μD(L)+μD(R) > best ? ----是----> 结束当前根
                         |
                        否
                         |
读取或复用第一侧精确 D 值
                         |
A(v)+D(first,v)+μD(other) > best ? --是--> 不读取第二侧
                         |
                        否
                         |
读取第二侧，执行原精确候选更新
```

**算法的外层结束条件没有变化。** 当前 A mask 的全部合法分块处理完后，该行 completion 结束；全部要求的 A masks 处理完后，求解结束。三级下界只让已经被证明无法改善上界的局部工作提前结束。

## 3. 正确性

### 3.1 统一下界证明

取任意能被旧 completion 检查的共同根 `v`。由最小值定义，

```text
μA(S) <= A(S,v),
μD(L) <= D(L,v),
μD(R) <= D(R,v).
```

逐项相加可知分块级下界不大于该根的精确候选值。把 `μA(S)` 替换为精确 `A(S,v)` 后得到更强但仍合法的根级下界；再把某一侧 `μD` 替换为同一根上的精确 D 值，得到更强但仍合法的分量级下界。因此任何一级严格大于 `best` 时，被省略的所有后续精确候选也都严格大于 `best`。

### 3.2 已裁剪行、空侧与单组侧

多组 D 行和 A 行的最小值只在当前存储支持集上计算。旧 completion 本来就只枚举这些支持集；先前被 admissible bound 删除的状态已经证明不能改善当时及之后单调不增的 incumbent。因此新下界相对于旧 completion 没有额外丢失可行候选。若某张多组行没有有限值，其最小值为正无穷，且该分块本来也没有共同根。空侧代价恒为 0；单组侧在本组顶点上距离为 0，所以 0 是合法且精确的全局最小值。

### 3.3 动态上界与浮点比较

共同根扫描过程中 `best` 只会下降，因此越晚执行同一下界只会增加安全拒绝，不会恢复已经拒绝的候选。实现保持精确候选的左结合次序，并且只在下界**严格大于** `best` 时拒绝。所有代价非负，IEEE 浮点加法对每个操作数单调；由逐项不大于可推出相同加法次序下舍入后的下界不大于对应精确候选。等值最优候选不会因 `>=` 被删除，因为代码没有使用 `>=`。

### 3.4 最终正确性证据

当前 Test107 Release/O2 源码通过以下 DPBF 黑盒对拍，误差阈值均为 `1e-6`：

```text
seed 716901  wide g2--g8  100/100
seed 716902  fixed g13     50/50
```

此前两个中间版本也分别通过 Test105 的 `100/100 + 50/50` 和 Test106 的 `100/100 + 50/50`。fast20、DBLP g13 q5、DBLP g13 q32 与 Toronto g13 的最终答案、ordinary values/pops、anchored values/pops 均与 Test104 完全相同。

## 4. 时空复杂度

设非锚点组数为 `k=g-1`。每个普通 mask 保存一个 double，额外持久空间为 `O(2^k)`；DBLP g13 对应 `2^12·8=32,768B=0.03125MiB`。A 行最小值是局部标量，三级判断不建立根表或新索引。

每张 D/A 行原本就要遍历其保留值，维护最小值只增加每值一次常数比较。每个合法 completion 分块增加 `O(1)` 的第一级判断；每个实际访问的 A 根至多增加两次 `O(1)` 判断。最坏情况下没有对象被拒绝，原求解器的状态、mask、partition、共同根和图闭包渐进上界均不变。实际工作则依次缩减为：

```text
只有分块级幸存者支付共同根枚举；
只有根级幸存者支付第一侧精确读取；
只有分量级幸存者支付第二侧精确读取与最终检查。
```

这组机制改变的是 completion 的实际输出工作量，而不是对原 word loop 设置经验阈值。它仍不减少 D/A 状态生成，因此端到端收益取决于 completion 在查询中的占比。

## 6. 论文边界与下一步

“用分量最小值替换精确分量得到和式下界”是标准代数事实，本文不把这个不等式本身声明为原创。可作为论文方法讨论的仓库贡献是：在永久锚点框架 A 中，把离线有序 D rows 的行摘要、锚定 A row 生命周期、无序 `A+D+D` 分块、物理共同根接口和 driver 已付值统一为一个**分块→根→分量的无参数、无 Hash completion 下界级联**。

### 6.1 相邻文献

- [PrunedDP](https://doi.org/10.1145/2882903.2915217) 已提出 GST 的 optimal-tree decomposition、conditional tree merging 与 progressive A*；因此本文不把“条件合并”“提前可行解”或“一般 A* 剪枝”当作新贡献。
- [Dijkstra Meets Steiner](https://arxiv.org/abs/1406.0492) 与后续 [DS*](https://arxiv.org/abs/2011.04593) 研究 Steiner 子集标签搜索中的 feasible/admissible lower bound。它们给出下界进入 label-setting 的一般背景，但不直接给出 permanent-anchor `A+D+D` 离线 completion 的分块、共同根、第二分量三级接口。
- [Separator-Based Pruned Dynamic Programming](https://doi.org/10.1609/aaai.v33i01.33011520) 利用输入图的小分隔结构裁剪 Steiner DP；当前方法不假设图 separator，也不把普通图压缩计作自身收益。

上述是围绕当前接口的窄范围边界核对，不等价于系统性新颖性检索。论文写作时应把“标准不等式”“已有通用搜索/剪枝背景”和“本仓库特定状态与物理接口组合”分开陈述。

三级级联已经在 q5、q32、Toronto 和 q25 上把最终 checks 削减约两个数量级；q25 仍有 `32.598B` scans，说明继续增加同类微层次的边际价值很低。下一理论目标应回到 D/A 状态物化之前的 anchor-aware 剪枝或新的可证明状态表示；不应加入数据集、固定 `g`、层号或时间特判，也不应把 baseline 同样可用的普通图/query 压缩计作本方法贡献。
