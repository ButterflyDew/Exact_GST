# Test119：锚路径设施上界

更新时间：2026-07-16。Test119 研究如何在不改变 Test107 permanent-anchor A 框架的前提下，把高层 D 才发现的可行解提前反馈给低层剪枝。机制不压缩图或询问，不切换到框架 B，不使用数据集、固定 `g`、固定块数、状态密度或 wall time 条件；它只复用 Test107 已生成的普通有序行与 junction 已支付的永久锚路径。

## 1. 动机

DBLP `g=15 q33` 的 Test107 完整运行在 D1--D3 后一直保持 `best=10.2642201136`，到 D4 结束才降到 `10.0181663554`。在这次改善发生前，D2--D4 已分别保留 `153.152M、419.590M、781.846M` 个 values；完整 wall 为 `11505.101s`，超过 8,000 秒目标 `3505.101s`。因此需要的不是 completion 常数优化，而是一个能在 D2/D3 完成后立即构造真实可行解的 anchor-aware 批量接口。

## 2. 状态与上界

设 `P` 是 junction 已恢复的永久锚路径。它从 root-star 根连接到永久锚组，路径成本记为 `c(P)`；`delta_P(v)` 表示顶点 `v` 到路径 `P` 的最短距离。对任意已经生成的非锚组子集 `S`，普通状态 `D(S,v)` 表示一棵覆盖 `S` 且以 `v` 为根的最低已保留成本。Test119 将整张有序行归约为一个锚路径接入代价：

```text
a(S) = min_v { D(S,v) + delta_P(v) }.
```

接着对全部非锚组集合 `Q` 做 subset partition DP。令 `F(M)` 是把集合 `M` 划分成若干个当前已有 D 行的最小接入代价，`b(M)` 是 `M` 的最低有效位：

```text
F(0) = 0,
F(M) = min { F(M \ B) + a(B) : B subseteq M, b(M) in B, a(B) finite }.
```

条件 `b(M) in B` 只用于规范化分区枚举，保证每个无序分区恰好出现一次；它不限制块大小或块数。当前层尚未生成的 mask 令 `a(B)=infinity`。层末候选上界为：

```text
U_facility = c(P) + F(Q).
```

算法在每个 D 层自然结束时都执行同一个递推。随着新 D 行可用，允许的分区只增不减，因此候选上界单调不增；没有“只在 D2/D3 启用”的求解策略。

## 3. 正确性

对最优分区中的每个块 `B`，取达到 `a(B)` 的普通状态见证树 `T_B`，再取其根到 `P` 的一条最短路。路径 `P`、全部 `T_B` 与全部接入最短路的并集是连通子图：`P` 覆盖永久锚组，每个 `T_B` 覆盖块 `B`，所有块构成非锚组全集。并集的真实成本不会超过各部分成本之和，即不超过 `c(P)+F(Q)`。因此 `U_facility` 是某棵真实可行 GST 的成本上界，可以安全写回 incumbent。

普通行中的值可能已经被 Test107 的合法下界筛过，但这不影响论证：保留下来的每个 `D(S,v)` 仍对应真实见证树。只在这些值中取最小值可能让 `a(S)` 变弱，不可能产生低于某棵可行树成本的虚假上界。

## 4. 实现

junction 本来就会对锚路径做一次多源最短路。公共接口增加可选输出参数；只有 Test118/119 请求并接管该距离数组，ReleaseV4 和普通 Test107 的调用路径不分配额外数组，也不改变行为。

对 singleton，`a(S)` 由组距离与 `delta_P` 的顺序数组扫描得到。对其余 mask，归约直接融合进已有 Store row 循环：无论最终选择 sparse、dense 还是 ranked bitmap，写入每个 value 时同时更新一个标量最小值，不增加第二次 row 扫描。层末 DP 使用长度 `2^(g-1)` 的连续数组和规范化 submask 枚举，不使用 Hash。

若 `h=g-1`，一次 partition DP 的最坏时间为 `O(3^h)`、空间为 `O(2^h)`；所有 D 行的接入归约只增加常数次顺序算术，不改变原有状态生成的渐进上界。锚路径距离在普通阶段结束后立即释放，不进入 A 阶段空间峰值。

融合归约后的 q33 D4 门继续使用相同上界，D4 后 `best=9.9770319196`。D4 本身没有再次改善 facility upper，但 D2/D3 提前反馈已经改变了整层输入：

| branches | `763,679,443` | `529,862,515` | `-30.62%` |
| pops | `1,171,751,427` | `803,433,448` | `-31.43%` |

从公共预处理到 D4 结束，Test107 完整记录中的分项和为 `3475.898s`，Test119 实测 gate wall 为 `2975.696s`，减少 `14.39%`。两者不是同次同机配对计时，因此端到端比例只作辅助；约 `30%` 的状态、分支、pops 与 row bytes 同向下降才是机制收益的主要证据。

当前累计节省仍不足以从 `11505s` 外推到 8,000 秒。随后实现过一个共享路径加强：记录 facility 最优分区的接入根，在 junction 的锚路径最短路树上对重合接入边只计费一次。该候选通过 `g=2--15` 随机 `100/100`，但 Toronto 与 q33 的 D2/D3 候选均与标量 facility **逐层完全相同**，没有减少任何状态；parent/root/split 代码已经撤回。保留的负结论是：当前最优 facility 分区的接入路径没有可利用的重复计费，继续优化同一组见证路径无效。

Test120 随后检验了层内反馈。它按新 row values 累计工作量，以 rent-or-buy 规则支付一次规范化 partition DP；D2 的首次有效更新出现在第 `82/91` 张 row，层末 values 额外减少 `1.94%`，D3 的首次更新直到第 `345/364` 张 row，层末只再减少 `0.20%`。D3 截止 wall 落在 Test119 的计时波动内。因此问题不在同一标量上界的反馈频率，而在上界仍未表达多个 D 块共享锚树边的结构。Test120 已完整撤回，证据见 `archive/test120_online_anchor_facility_20260716.md`。

下一步只研究更强的结构性上界：在已有 junction 压缩锚树上组合 rooted D-block，使多个块可以共享锚树边；先比较逐层候选强度，再决定是否写回 incumbent。该方向仍复用 permanent-anchor A 框架、普通有序行和自然层边界，不启动完整 q33。
