# Test121：压缩锚树上的 D-block 设施上界

更新时间：2026-07-16。Test121 沿用 Test107 的 permanent-anchor A 框架与 Test119 的普通有序行，不改变状态语义、状态生成顺序或精确停止条件。它只加强层末可行上界：多个 rooted D-block 不再各自独立连接到锚路径，而是在已有 junction 压缩锚树上汇合，使共同使用的锚树边只付费一次。

## 1. Test119 缺失的结构

Test119 将每张已完成普通行归约为 `a(S)=min_v D(S,v)+delta_P(v)`，再把若干块的 `a(S)` 相加。该上界合法且有效，但每个块都独立支付到永久锚路径 `P` 的最短路。即使两个块可以先在同一锚树分支汇合，它也不会主动选择略贵的 rooted D 状态来换取后续共享边。

Test121 使用 junction 已经构造的最短路父树。该树以锚路径为零成本根集合，并只保留 junction 候选根、候选根到锚路径的祖先路径以及分叉点；压缩后得到树 `T`。DBLP `g15 q33` 的 `T` 只有 `17` 个普通节点，因此可以在这棵小树上保留 rooted block 结构，而不回到全图状态空间。

## 2. 节点内的 D-block 划分

记全部非锚组集合为 `Q`，`h=|Q|`。在当前 D 层结束时，singleton 与已经生成的普通行都可作为 block。对压缩树节点 `x`，定义：

```text
c_x(B) = D(B,x),                 若 B 的普通行已经可用；
c_x({i}) = dist(i,x),            singleton；
c_x(B) = infinity,               其余情况。
```

普通行可能因合法下界没有保留顶点 `x`，此时对应值就是 infinity。随后计算在同一节点汇合的局部设施代价 `L_x(M)`：

```text
L_x(0) = 0,
L_x(M) = min { L_x(M\B) + c_x(B) : B subseteq M, lowbit(M) in B }.
```

`lowbit(M) in B` 只规范化无序分区，不限制 block 大小或数量。`L_x(M)` 的每个方案都是若干棵 rooted D 见证树在共同根 `x` 的并集，因此覆盖 `M` 且连通到 `x`。

## 3. 压缩锚树卷积

对压缩树节点 `x`，令 `H_x(M)` 表示覆盖组集 `M`、并与 `x` 连通的最小已构造成本。处理子节点前，令 `H_x=L_x`。若子节点 `y` 到 `x` 的压缩边长度为 `ell(x,y)`，则做一次 disjoint-subset 卷积：

```text
H'_x(M) = min over B subseteq M {
    H_x(M\B) + H_y(B) + [B != 0] * ell(x,y)
}.
```

当 `B` 非空时，子树确实承载 D-block，压缩边支付一次；无论子树中有多少块，这条边都不会重复计费。所有子节点依次合并后得到最终 `H_x`。锚路径上方增加一个虚拟根 `r`，它没有本地 block，并以零长度边连接各锚路径分支。最终候选为：

```text
U_tree = cost(P) + H_r(Q).
```

实现同时保留 Test119 的 `U_facility`，层末写回 `min(U_facility,U_tree)`。因此压缩树候选较弱时不会覆盖已有设施上界。

## 4. 正确性

对叶节点，`L_x(M)` 中每个 block 都有一棵真实 rooted D 见证树，所有见证树在 `x` 相交，所以其并集覆盖 `M` 并连接到 `x`，真实并集成本不超过求和成本。

假设每个已处理子节点的 `H_y(B)` 都对应一棵覆盖 `B` 并连接到 `y` 的真实子图。卷积选择互不相交的 `B` 与 `M\B`，并在 `B` 非空时加入 `y` 到 `x` 的真实压缩树路径；两部分于是连接到同一节点 `x`。即使 D 见证树或不同压缩路径存在重合，公式只会重复计费，不会低估并集成本。对子树自底向上归纳，`H_r(Q)` 对应覆盖全部非锚组并连接到锚路径的真实子图；再加入永久锚路径后得到完整可行 GST。因此 `U_tree` 是合法上界，可以安全写回 incumbent。

## 5. 复杂度与实现边界

设压缩锚树有 `t` 个普通节点。每个节点的规范化 local partition 与每条树边的 disjoint-subset convolution 都在 `O(3^h)` 内，因此每个自然 D 层的时间为 `O(t*3^h)`，空间为 `O(t*2^h)`。DBLP `g15 q33` 中 `h=14、t=17`，实测每层约 `122M` 次简单数组递推，D1 为 `0.346s`。数据结构全部是连续数组、树邻接表和已有 sorted row 的定点读取，不使用 Hash。

公共 junction 接口只增加一个可选 `AnchorTree` 输出。ReleaseV4 和普通 Test107/Test119 不请求该输出时，仍走原调用路径；求解器没有按数据集、固定 `g`、固定层、密度或 wall time 分支。候选在每个自然 D 层末用同一递推计算，树 DP 数组在普通阶段结束后释放。

Test122 随后把所有普通 row 顶点沿最短路父树投影到最近压缩节点，使节点 block cost 理论上同时支配 Test119 与 Test121。该 profile 通过随机正确性门，但 Toronto g13 q1--q5 的逐层候选和状态与 Test121 完全相同，只增加全图数组与写入，因此已撤回且没有启动 DBLP。证据见 `archive/test122_projected_anchor_tree_profile_20260716.md`。这说明下一步不能只扩充同一压缩节点的 rooted cost 来源，而需要新的锚树拓扑或不同的结构信息。

Test123 又用完整 D3 row 的精确 attachment roots 扩张同一最短路父树。Toronto panel 中 q2 的压缩树从 `52` 增至 `98` 个节点、q4 从 `38` 增至 `65`，但五条询问的上界和状态仍逐项不变；该分支也已撤回且没有启动 DBLP，见 `archive/test123_exact_triple_anchor_tree_20260716.md`。因此后续不再向这棵父树增加 facilities、投影根或 exact triple roots。

Test124 放弃固定父树，在相同 junction sites 的全最短路度量闭包上运行 Steiner subset DP。它在 q33 D2 将 values 再降 `2.45%`，但 Toronto g13 q1--q5 完整总 wall 回退 `1.29%`，因此已撤回且没有进入 DBLP D3，见 `archive/test124_anchor_metric_closure_20260716.md`。这进一步排除了“只放宽同一 sites 的连接拓扑”作为主线突破；后续应寻找能直接改变 D4/A6 的锚感知状态接口。

Test121 本身没有新增论文引用。Test124 的度量闭包递推与经典 Dreyfus--Wagner Steiner subset DP 同源，归属与链接已在其归档中明确说明。当前文档不据此声称文献层面的首创性；进入论文主线前仍需单独完成相关工作检索。
