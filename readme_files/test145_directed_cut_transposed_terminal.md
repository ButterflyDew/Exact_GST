# Test145：有向割约化的转置终端生成

更新时间：2026-07-16。Test145 是 Test142 伴随锚点格的活动研究后继，不是发行版。它保留 ordinary D、永久锚、root-irreducible branch、低层正向 A、高层反向 H、离线有序行以及完整的 `A+D+D` 状态语义；唯一的核心变化是：**高层 H 的终端源不再按目标 mask 重复枚举补集划分，而是在每个根顶点上一次处理所有 ordinary mask。** ReleaseV4 和默认 Test80 均未改变。

## 1. Test142 留下的问题

设锚组之外的组集合为 `K`，`k=|K|=g-1`。Test142 对高层 anchored mask `T` 建立反向行 `H_T`，其初始终端函数是

```text
G_T(v) = min D(L,v) + D(R,v),
```

其中 `L`、`R`、`T` 两两不交且并为 `K`，ordinary 两侧大小均不超过 `h=floor(g/2)`。Test142 逐个 `T` 枚举 `K-T` 的划分，再对每个共同根读取两张 D 行。DBLP g15 q33 最终只保留 `6.774M` 个 H 值，却做了 `54.808B` 次 join checks，伴随阶段耗时 `2083.777s`。这说明瓶颈已经不是 H 行驻留，而是**同一批 D 值被不同目标反复组合和重复执行前缀下界**。

Test145 不删除任何终端划分，也不压缩图或查询。它只交换两层循环：从“目标 `T` -> 划分 `(L,R)` -> 根 `v`”改为“根 `v` -> 可用 ordinary mask -> 目标 `T`”。

## 2. 可共享的有向割恒等式

记 directed-cut 下界在根 `v` 上对单组 `i` 的势为 `pi_i(v)`，对组集合的势按组相加：

```text
pi_X(v) = sum over i in X of pi_i(v).
```

令 `a` 表示永久锚组。对任意合法终端划分 `L union R union T = K`，有

```text
D(L,v) + D(R,v) + pi_(a union T)(v)
= [D(L,v) - pi_L(v)]
  + [D(R,v) - pi_R(v)]
  + pi_(a union K)(v).
```

右端最后一项在固定根 `v` 上与 `L/R/T` 全部无关。因此定义 ordinary 值的约化代价

```text
r(S,v) = D(S,v) - pi_S(v)
```

以及该根的统一预算

```text
beta(v) = best - pi_(a union K)(v).
```

一个二块终端只有在

```text
r(L,v) + r(R,v) <= beta(v)
```

时才可能改善当前上界；单块终端对应 `r(L,v)<=beta(v)`。**原来依赖目标 `T` 的 directed-cut 判断由此变成了根顶点上的统一判断。** 这是转置能够共享剪枝的关键，而不是数据集、固定 `g`、层号或运行时刻特判。

## 3. 主流程

Test145 在 ordinary D 和低层 A 完成后执行以下步骤。

1. **按根收集 ordinary 值。** 所有 ordinary 行已经按顶点有序，并采用 sparse、dense 或 ranked-bitmap 表示。实现以 64 个连续顶点为一个流式批次，同时顺序读取各行；对每个根 `v` 得到列表 `V_v={(S,D(S,v))}`。这一步不建立 Hash，也不改变 D 行内容。
2. **计算约化值并排序。** 对列表中的每个状态计算 `r(S,v)`，按 `r` 非降序排列。每个 mask 的势由单组势按位递推并在当前根内记忆。
3. **生成单块终端。** 对所有 `r(S,v)<=beta(v)` 的值，令目标 `T=K-S`，用 `D(S,v)` 更新 `G_T(v)`。这覆盖另一 ordinary 块为空的奇偶边界。
4. **生成二块终端。** 枚举满足 `L intersect R` 为空且约化和不超过预算的 mask 对，令 `T=K-(L union R)`，只保留该 `<T,v>` 的最小 `D(L,v)+D(R,v)`。
5. **执行完整前缀下界。** 聚合后再对 `anchor union T` 检查 farthest、group-tour 与 directed-cut 三项下界。只有仍可能改善 `best` 的 `<T,v>` 才写入按 `T` 分组、按 `v` 有序的终端事件。
6. **照旧求高层 H。** H 行按 mask 大小递减生成。终端事件只是原 `G_T` 的稀疏输入；高层反向转移、最短路闭包和跨切分边都与 Test142 相同。每张 H 行完成后立即与已存在的低层 A 行结算边界，因而后续层可以使用更小的合法上界。

转置阶段在进入 H 之前结束；H 的结束条件仍是所有 `c<|T|<=h-1` 的反向行及其跨切分边处理完毕。最终答案仍是低层直接 completion 与所有跨切分候选的最小值。

## 4. 两条精确枚举路线

只使用全局排序后的双循环在实测中很快，但最坏会检查大量相交 mask 对，不能直接给出 `O(3^k)` 组合界。当前实现因此在**每个根顶点**计算两条路线的精确探测数，并选择较小者。

### 4.1 全局有序路线

排序后用单调右端点计算满足 `r(L,v)+r(R,v)<=beta(v)` 的所有数值对数量 `W_sort(v)`，随后只扫描这段前缀并过滤相交 mask。右端点只向左移动，计数本身为线性时间。

### 4.2 补集子掩码路线

对每个现有 `L`，只枚举 `K-L` 的非空子掩码 `R`；不存在的 D mask 用直接数组标记跳过，并用固定 mask 次序去重。该路线实际会检查

```text
W_sub(v) = sum over L in V_v of (2^(k-|L|) - 1)
```

个子掩码。实现选择 `min(W_sort(v),W_sub(v))` 对应的路线，没有经验常数或阈值。

因为选择全局路线时有 `W_sort(v)<=W_sub(v)`，选择子掩码路线时恰好执行 `W_sub(v)` 次检查，所以无论选择哪条路线，实际 pair probes 都满足

```text
W(v) <= W_sub(v) <= 3^k.
```

这一步把初版全局双循环可能出现的 `O(4^k)` 最坏界恢复到与原补集划分相同的 `O(3^k)`，同时保留约化排序在实际强预算下的提前结束能力。

## 5. 正确性

**引理 1：约化预算等价。** 第 2 节恒等式是 directed-cut 势的可加性直接展开，因此原条件 `D(L)+D(R)+pi_(a union T)<=best` 与 `r(L)+r(R)<=beta` 完全等价。

**引理 2：两条路线覆盖同一终端。** 全局路线检查预算内的所有数值对，再保留不相交对；子掩码路线对每个 `L` 直接枚举全部不相交 `R`。两者都覆盖且只覆盖所有合法无序对，并显式覆盖单块终端。

**引理 3：按 `<T,v>` 聚合不改变 H。** 原终端函数只需要同一目标、同一根上的最小值。转置先取该最小值再送入闭包，与逐划分调用 `min` 等价。

**引理 4：预先按 incumbent 删除是安全的。** 转置阶段删除的终端在当时已经大于 `best`。H 计算只可能继续减小 `best`，所以被删除终端之后也不可能成为改进候选。

结合 Test142 的伴随格等价性，可得：**Test145 返回值与完整正向 permanent-anchor A 格一致。** 独立探针不调用生产转置代码，而是分别构造逐目标终端、全局约化终端和补集子掩码终端，在多个预算下逐状态比较；生产实现再由 DPBF 黑盒对拍。

## 6. 复杂度与空间

令 `M_v=|V_v|`，`Q=sum_v M_v`，`E` 为通过全部下界后保存的终端事件数。转置终端的时间为

```text
O(sum_v M_v log M_v + sum_v W(v) + E)
subseteq O(k Q + n 3^k + E).
```

加上 Test142 原有的高层 H 闭包，整体最坏时间仍为

```text
O(3^k n + N_H (m + n log n)),
```

其中 `N_H=sum_(i=c+1)^(h-1) C(k,i)`。额外工作空间是 mask 直接数组、单个 64 顶点批次的临时列表和终端事件，即 `O(2^k + max_batch + E)`；高层 H 行空间界仍为 `O(N_H n)`。实现不使用 Hash。

fast20 中有 `49,194` 个根实例选择全局有序路线，`4` 个选择补集子掩码路线；pair probes 为 `17.779M`，低于初版的 `17.920M`，终端事件保持 `223,757`。初版 Toronto g15 q1--q5 为 `391.092s`；有界版进一步降到 `387.645s`，说明恢复理论上界没有牺牲该面板的机制收益。

Toronto 有界版的 ordinary 阶段为 `283.546s`，伴随阶段为 `49.747s`，其中转置构造 `39.482s`；Test144 对应伴随阶段为 `201.209s`。pair probes 从初版 `5.845B` 降到 `5.146B`，其中全局有序路线 `3.898B`、补集子掩码路线 `1.248B`；两条路线分别被 `221,696/426` 个根实例选择。最大 query peak 为 `345.203MiB`，Test144 为 `330.102MiB`，即用约 `15.1MiB` 峰值换取跨目标共享。

DBLP g15 q33 相对 Test142 的 `9058.212s` 改善 `16.15%`，相对 Test107 的 `11505.101s` 改善 `33.99%`。本次 ordinary D 实际为 `6493.381s`，反而比 Test142 的 `6137.372s` 慢 `5.80%`；主要收益完全来自 anchored 阶段 `2846.594s -> 1024.499s`，其中伴随阶段 `2083.777s -> 276.020s`，下降 `86.75%`。completion 为 `122.601s`，与 Test142 的 `122.986s` 基本一致。

该长门的转置阶段顺序读取 `1.297B` 个 ordinary values，执行 `3.695B` 次 pair probes，并在 `170.217s` 内生成 `5.044M` 个终端事件；事件逻辑空间为 `71.23MiB`。全局有序路线由 `2,497,479` 个根实例选择，补集子掩码路线只由 `303` 个根实例选择，但后者承担 `1.356B` 次探测，说明精确择优不是只为形式复杂度准备的死分支。随后 H 转移执行 `86.750M` 次 checks，最终保留 `6.677M` 个 H 值和 `9.444M` 次 pops。query peak 相对 Test142 增加 `108.785MiB`（`0.76%`），但仍比 Test107 低 `24.84%`。

因此当前主要瓶颈已经再次转移：ordinary D 占总 wall 的 `85.50%`，转置加全部 H 只占约 `3.63%`。后续若继续研究，应减少 ordinary D 的状态生成、seed candidates 或图传播；继续压缩高层终端的常数已不足以形成同量级收益。

## 8. 文献与原创性边界

Test145 继承 Test142 对经典 Dreyfus--Wagner rooted subset DP 的使用；来源为 [Dreyfus and Wagner, 1971](https://doi.org/10.1002/net.3230010302)。经典同根 subset merge、最短路闭包和一般的 directed-cut 下界不在本文中主张原创。当前候选贡献是仓库内推导的组合：在 permanent-anchor 伴随格中利用组势可加性，将目标相关终端判断转成按根共享的约化预算，并以精确工作量择优保持 `O(3^k)`。尚未完成系统文献检索，因此本文只称其为“论文候选机制”，不作新颖性定论。
