# Test152 核心算法正确性核对：从 `D/A` 到 `F/H` 与转置终端

更新时间：2026-07-18。本文是 Test152 的**源码对齐证明稿**，核对 ReleaseV6 来源主线的状态语义、完备性、剪枝安全与核心复杂度。正式方法说明见 `release_v6_method_cn.md`，评审结论见 `release_v6_review_gate.md`。

## 1. 问题、记号与证明范围

给定无向图 `G=(V,E)`、非负边权和查询组 `T_0,...,T_(g-1)`，Group Steiner Tree 要求找到一棵最小权连通子图，使其至少命中每个组的一个顶点。查询组允许重叠，同一顶点可以同时命中多个组。

固定一个永久锚点组 `T_a`，其余非锚组的集合记为 `K`，`k=|K|=g-1`。令

```text
h = floor(g/2),
a = h-1,
c = floor(a/2).
```

Test152 的核心状态为：

```text
D_S(v): 覆盖普通组集合 S，并包含根 v 的最小树成本；
A_S(v): 覆盖锚点组与普通组集合 S，并包含根 v 的最小树成本；
F_S(v): A_S 已在根 v 完成图闭包后，从该状态继续到完整终端的原始后缀成本；
H_S(v): 把 F_S 经一次无向最短路闭包拉回到前驱合并根后的成本。
```

其中 `S subseteq K`，空普通状态约定 `D_empty(v)=0`。定义图闭包算子

```text
C(f)(v) = min_u [f(u) + dist_G(u,v)].
```

**必须区分 `F` 和 `H`。** `F_S(v)` 才是“已经位于闭包后的 `(S,v)`，从这里继续”的成本；源码保存的 `backward[S]` 是

```text
H_S = C(F_S),
```

它已经替一条进入 `S` 的正向依赖反向跨过了图闭包。源码没有单独存储 `F`：它先把 `F` 的候选写入 `row_distance`，随后执行 Dijkstra 闭包，并把闭包结果作为 `H` 保存。

本文证明的是未剪枝数学递推与标准精确 DP 等价，并进一步证明 incumbent 剪枝不会删除任何能够改进当前可行上界的推导。设施上界、锚树上界、渐进 dual 与剩余容量打包只产生合法界或改变求值时机，不参与核心完备性定理。

## 2. 算法主线

Test152 可以按下面五步理解。

1. 生成所有 `1<=|S|<=h` 的普通状态 `D_S`，并从中发布可交给更高层合并的 root-irreducible 分支 `Br_S`。
2. 以 `A_empty(v)=dist(v,T_a)` 为起点，只正向物化 `|S|<=c` 的低层锚定状态。
3. 每张低层 `A_S` 完成后，直接枚举剩余组的两个普通块，结算 `A+D+D` 终端。
4. 对 `c<|S|<=a` 的高层锚定格不再物化 `A_S`，而从 `A+D+D` 终端反向计算 `F_S` 和 `H_S=C(F_S)`。
5. 每张高层 `H_T` 完成后，枚举它的第一条低层到高层边，以 `A_S+Br_(T-S)+H_T` 结算。高层直接终端由按根转置过程一次生成。

下面的定理链分别说明：为什么只需三块、为什么 `Br` 不丢解、为什么反向格与完整正向格等价，以及转置为什么没有改变任何终端值。

## 3. 平衡的 `A+D+D` 分解

### 3.1 组权重树与平衡根

**引理 1（组权重平衡根）。** 对任意最优 GST 解，都存在一棵同成本最优树 `T*`、每个查询组的一个代表命中顶点，以及树上一个顶点 `r`，使删除 `r` 后每个连通分量包含的代表组数至多 `h=floor(g/2)`。

**证明。** 非负边权下可以从最优连通子图中删除环边，并继续删除不影响所选代表连通性的冗余边，得到一棵最优树。为每个组在树中固定一个代表；若多个组选择同一顶点，就在该顶点累计相应的整数权重。树的总权重为 `g`。取这棵顶点加权树的加权重心 `r`，则删除 `r` 后每个分量的权重至多总权重的一半，也就是至多 `floor(g/2)=h`。该论证只使用组标签计数，不要求代表顶点互异，也不依赖边权严格为正。证毕。

### 3.2 至多三个容量为 `h` 的组块

删除平衡根 `r` 后，把每个含代表的连通分量视为一个物品，物品大小为其中的代表组数；位于 `r` 本身的每个组标签视为一个大小为 1 的物品。每个物品大小至多 `h`，总大小为 `g`。

**引理 2（三箱打包）。** 当 `g>=2` 且 `h=floor(g/2)` 时，任意一组总和为 `g`、单项不超过 `h` 的正整数物品，都可以分到至多三个容量为 `h` 的箱中。

**证明。** 当物品多于三个时，反复合并当前最小的两个物品。设四个最小物品为 `x1<=x2<=x3<=x4`。若 `x1+x2>h`，由于取值为整数，`x1+x2>=h+1`，且 `x3+x4>=h+1`，于是总和至少为 `2h+2`；但 `g` 只能是 `2h` 或 `2h+1`，矛盾。因此每次合并都不超过 `h`。继续到至多三个合并项，即得到所需分箱。证毕。

每个箱取根 `r`，并加入箱内分量到 `r` 的全部树边；位于 `r` 的标签可以独立分配，因为 `r` 同时属于所有根子树。由此得到至多三个只在根处相交的 rooted 子树。若少于三个，就补空块。

### 3.3 锚定版本

**定理 1（Group-balanced `A+D+D` 分解）。** 对 `g>=2` 的任意最优 GST 解和任意指定锚点组，都存在一个根 `r` 以及互不相交的组块 `S,L,R`，满足：

```text
S union L union R = K,
|S| <= h-1 = a,
|L| <= h,
|R| <= h,
```

并且该最优树可分为一个覆盖锚点与 `S` 的 rooted 部分，以及两个分别覆盖 `L`、`R` 的普通 rooted 部分。

**证明。** 使用引理 2 得到至多三个容量为 `h` 的箱。把锚点代表标签所在的箱指定为锚定箱；该箱总共至多包含 `h` 个组，其中一个是锚点，所以至多包含 `h-1` 个非锚组。其余两个箱分别作为 `L`、`R`，大小均至多 `h`。若锚点代表就是 `r`，把该标签分配给任意一个箱即可；若多个组共享 `r`，这些标签仍可逐个分配；若多个组共享非根代表，它们留在同一个分量物品中，而平衡根性质已经保证该物品不超过 `h`。零权边不影响树分量与标签计数；空普通箱按 `D_empty=0` 处理。证毕。

这一定理给出精确性所需的存在性方向：在根 `r` 上，某个合法 `A_S(r)+D_L(r)+D_R(r)` 不超过最优树成本。反方向也成立，因为任意三棵 rooted 状态树的并集都是命中全部组的连通子图，其并集成本不超过三项之和，所以任何 DP 候选都不可能小于全局最优值。两边合并后，`|S|<=a`、`|L|,|R|<=h` 的状态足以取得精确最优值。

## 4. 普通状态与 root-irreducible branch

### 4.1 标准递推

对 `|S|>=2`，固定 `S` 中编号最小的组为 pivot `p(S)`，定义标准同根 seed：

```text
M_S(v) = min {
    D_(S-Q)(v) + D_Q(v)
    : empty != Q proper-subset S, p(S) notin Q
}.
```

标准 rooted subset DP 满足 `D_S=C(M_S)`。固定 pivot 只去掉左右交换的重复，不改变分割集合。

Test152 定义发布接口：

```text
Br_S(v) = D_S(v),                         if |S|=1;
Br_S(v) = D_S(v),                         if |S|>=2 and D_S(v)<M_S(v);
Br_S(v) = infinity,                       otherwise.
```

直观上，`D_S(v)<M_S(v)` 表示最优 `S` 子树必须先在别处合并，再经图路径闭包到达 `v`；它不能在当前根 `v` 以等成本继续拆成两个同根子树。**严格 `<` 是定义的一部分。等值状态不是丢弃，而是允许在当前根重新结合。**

### 4.2 源码实际递推

源码并不先计算标准 `M` 再筛选，而是直接令 pivot-free 一侧必须来自 `Br`：

```text
M^Br_S(v) = min {
    D_(S-Q)(v) + Br_Q(v)
    : empty != Q proper-subset S, p(S) notin Q
},
D^Br_S = C(M^Br_S).
```

随后又以 `D^Br_S(v)<M^Br_S(v)` 发布多组 `Br_S(v)`。这看起来比标准递推少了候选，下面说明它实际构成完备的规范化基。

### 4.3 完备性

**定理 2（branch-basis completeness）。** 在不考虑 incumbent 剪枝时，对所有 `S` 和 `v`，Test152 的递推满足 `M^Br_S(v)=M_S(v)`、`D^Br_S(v)=D_S(v)`。因此只让 pivot-free 一侧读取 `Br` 不会丢失任何最优普通状态。

**证明。** 对 `|S|` 归纳。单组是组距离，二组由两个单组直接合并，结论成立。假设所有真子集都已成立。由于 `Br_Q` 只取精确 `D_Q` 值，`M^Br_S` 的每一项也是标准 seed，因此 `M^Br_S>=M_S`。

反过来，取达到 `M_S(v)` 的一个标准分割 `(S-Q,Q)`。若 `Br_Q(v)` 已发布，该项直接出现在 `M^Br_S(v)` 中。否则，闭包允许选择零长度路径，所以 `D_Q(v)<=M^Br_Q(v)`；未满足严格不等式只能说明 `D_Q(v)=M^Br_Q(v)`。于是存在 `Q=P union B`，其中 `B` 是该 seed 的 pivot-free 已发布分支，并且

```text
D_Q(v) = D_P(v) + Br_B(v).
```

把 `P` 重新结合进原来的 pivot 累计侧，得到合法分割 `((S-Q) union P, B)`。原 pivot 仍在累计侧，`B` 仍是已发布分支，并且

```text
D_((S-Q) union P)(v) + Br_B(v)
<= D_(S-Q)(v) + D_P(v) + Br_B(v)
= D_(S-Q)(v) + D_Q(v)
= M_S(v).
```

左端是 `M^Br_S` 的合法候选，所以 `M^Br_S<=M_S`。与前一方向合并得到 seed 相等，再经同一个闭包 `C` 得到 `D^Br_S=D_S`。证毕。

该证明同时覆盖三个容易误判的边界：

- **等值拆分：** 等号使未发布侧能够在同一根重新结合，而不是被删除。
- **零权边：** 零长度闭包只会增加等值情形；归纳仍通过严格减小的组子集终止。
- **共享代表：** 多个单组距离可以在同一顶点同时为零，但单组始终可作为 `Br`，所以归纳基不消失。

## 5. 锚定正向格

锚定基行为

```text
A_empty(v) = dist(v,T_a).
```

对非空 `S`，锚定侧吸收任意非空普通块 `B subseteq S`：

```text
A_S = C(min_(empty != B subseteq S) [A_(S-B) + Br_B]).
```

每条依赖严格增加 mask，因此形成有向无环图。依据定理 2，以 `Br` 代替任意普通侧不会损失标准 `A` 递推的最优值。每个 `|S|<=a` 的状态都有直接终端

```text
G_S(v) = min {
    D_L(v)+D_R(v)
    : L disjoint-union R = K-S, |L|<=h, |R|<=h
}.
```

其中允许 `L` 或 `R` 为空。由定理 1，完整正向格的答案为

```text
OPT = min_(|S|<=a) min_v [A_S(v)+G_S(v)].
```

## 6. 高层格的 `F/H` 伴随求值

### 6.1 为什么需要两个反向量

设正向边 `S -> T=S union B` 的算子为

```text
T_B(f) = C(f+Br_B).
```

在 min-plus 内积 `<f,q>=min_v[f(v)+q(v)]` 下，无向距离对称，因此

```text
<C(f),q> = <f,C(q)>.
```

于是

```text
<T_B(f),q>
= <C(f+Br_B),q>
= <f+Br_B,C(q)>
= <f,Br_B+C(q)>.
```

也就是说，一条正向边的反向作用不是简单加 `Br_B`，还必须把后继函数先做一次闭包。为避免把这次闭包隐藏在状态名字中，定义：

```text
F_T(v) = 已经得到闭包后的 A_T(v) 时，从同一根 v 继续的最小后缀；
H_T(x) = min_v [dist(x,v)+F_T(v)] = C(F_T)(x).
```

`H_T(x)` 的根 `x` 是**进入 `T` 的合并发生处**，而 `F_T(v)` 的根 `v` 是**该正向边完成闭包后的位置**。

### 6.2 反向递推

只对高层 `c<|T|<=a` 求值。它们按 `|T|` 递减处理：

```text
F_T(v) = min(
    G_T(v),
    min_(empty != B subseteq K-T, |T union B|<=a)
        [Br_B(v) + H_(T union B)(v)]
),

H_T = C(F_T).
```

第一项表示在 `T` 直接完成；第二项表示在根 `v` 吸收普通块 `B`，再由 `H_(T union B)` 反向支付该正向边的闭包及更晚后缀。源码中的 `row_distance` 在 Dijkstra 前保存上述 `F_T` seed，Dijkstra 后的 `backward[T]` 才是 `H_T`。

反向递推必须枚举所有 strict-superset 边，包括一次吸收多个组并跨过若干层的 block。只传播 singleton 或相邻层不是等价简化。

### 6.3 第一条跨切分边

完整正向 `A` 路径的 mask 严格递增。若其终端 mask 位于低层 `|S|<=c`，低层直接 `A_S+G_S` 已经结算。否则，路径上存在唯一第一条从低层 `S` 进入高层 `T=S union B` 的边。根据上一节的伴随恒等式，这条边以及其后的全部高层后缀在低层根 `v` 上贡献

```text
A_S(v) + Br_B(v) + H_T(v).
```

**边界处必须使用 `H_T`，不能使用 `F_T`。** 因为从低层合并根进入 `T` 还要执行一次正向图闭包，而这次闭包已经被吸收到 `H_T=C(F_T)` 中。

**定理 3（adjoint equivalence）。** “所有低层直接终端”与“所有第一条低到高边 `A+Br+H`”的最小值，等于物化全部 `|S|<=a` 正向 `A` 行后得到的最小值。

**证明。** 对任意完整正向推导，按终端是否位于低层分成上述两类。高层推导有唯一第一条跨切分边；逐次使用闭包自伴随恒等式，可把该边之后的每个正向算子按相反顺序移到终端一侧，恰好得到递推中的 `F/H`，且值不变。反过来，`F_T` 的每个终端项对应原节点 `T` 的直接 completion，每个 successor 项对应原 DAG 的一条真实边；因此任意反向推导都能恢复成一条原正向推导，不会制造额外候选。两边集合逐推导对应，最小值相同。证毕。

## 7. 按根转置的高层终端

### 7.1 恒等式

对每个查询组 `i`，令 directed-cut 势在根 `v` 的值为 `pi_i(v)`，并令 `pi_X(v)=sum_(i in X) pi_i(v)`。渐进 dual 尚未构造的组取零势；因此无论当前使用部分势还是完整势，组可加性都成立。

对两两不交且 `L union R union T=K` 的合法终端，有

```text
D_L(v)+D_R(v)+pi_(a union T)(v)
= [D_L(v)-pi_L(v)]
  + [D_R(v)-pi_R(v)]
  + pi_(a union K)(v).
```

在固定根 `v` 上，最后一项与目标 `T` 无关。定义

```text
reduced(S,v) = D_S(v)-pi_S(v),
budget(v) = best-pi_(a union K)(v).
```

若 `reduced(L,v)+reduced(R,v)>budget(v)`，则 `D_L+D_R+pi_(a union T)>best`。由于 `pi_(a union T)` 是 `A_T(v)` 的合法下界，该终端不可能改善 incumbent，可以安全省略。该式既是过滤条件，也是把“逐目标枚举”改写成“固定根统一枚举”的依据；它没有用约化值替代真实终端值。

### 7.2 原枚举与转置事件的双射

对固定根 `v`，转置过程收集所有存在的 `(S,D_S(v))`：

- 单个 entry `L` 生成目标 `T=K-L`，对应原终端无序二分 `{L,empty}`；
- 两个不相交 entry `L,R` 生成目标 `T=K-(L union R)`，对应原终端无序二分 `{L,R}`；
- mask 顺序只用于让无序对出现一次；同一 `<T,v>` 的多个事件取最小真实值 `D_L(v)+D_R(v)`。

因此，在不使用 incumbent 过滤时，每个原 `G_T(v)` 候选恰好对应一个转置事件，反之亦然；取最小后逐目标的 `G_T(v)` 完全不变。使用过滤时，只删除由上节不等式证明不能改善 `best` 的事件，所以精确答案仍不变。

### 7.3 两条枚举路线

源码可以选择：

1. 按 reduced cost 排序，枚举预算内的数值对，再检查 mask 不相交；
2. 对每个 `L` 枚举 `K-L` 的非空子掩码 `R`，天然保证不相交，再以 mask 顺序去重。

它先精确计算两条路线将执行的 probe 数，再执行较小者。选择条件来自本根的实际枚举工作量，不是数据集、固定 `g`、wall time 或经验阈值，并且两条路线产生同一事件集合。

## 8. Incumbent 剪枝安全性

### 8.1 通用条件

`best` 始终由一棵真实可行树产生。若状态当前已付成本为 `x`，其未完成部分的下界为 `L`，则只在

```text
x+L > best
```

时删除；等号保留。只要 `L` admissible，任何能够得到严格更优完整解的推导都不可能被删除。若 `best` 已等于最优值，即使某些等价最优推导不再需要，当前可行解本身已经保证答案。

普通 `D` 与低层 `A` 使用的是对尚未纳入组的 farthest、tour 与 directed-cut 下界的最大值。三项分别合法，最大值仍合法；分阶段懒计算只避免不必要的下界求值，不改变最终判定式。

### 8.2 `F/H` 的前缀下界

反向行使用

```text
P_T(v) = max(
    farthest(anchor union T, v),
    tour(anchor union T, v),
    dual(anchor union T, v)
).
```

它满足 `P_T(v)<=A_T(v)`。因此：

- 对原始 seed `F_T(v)`，若 `F_T(v)+P_T(v)>best`，任何经过闭包后状态 `(T,v)` 的完整推导都不能改善上界。
- 对闭包值 `H_T(x)`，任意进入 `T` 的具体正向前缀在合并根 `x` 的成本至少为 `A_T(x)>=P_T(x)`，所以 `H_T(x)+P_T(x)>best` 同样可以删除。
- 三个前缀项都满足 `P_T(x)<=dist(x,y)+P_T(y)`，最大值保留该一致性。若在 `x` 删除值 `q`，则它沿任意边传播到 `y` 后有 `q+dist(x,y)+P_T(y)>=q+P_T(x)>best`，不会在别处重新变得有用。

转置终端先使用 additive dual 的预算过滤，再使用完整 `P_T` 过滤。两次都只删除不能改善当前可行上界的事件。

### 8.3 剪枝后的 `Br`

源码以通过剪枝的 `split_distance` 判定 strict branch。若某个同根 seed 被界拒绝，而同一根后来由闭包到达，源码可能比未剪枝数学定义**多发布**一个 `Br` 根。该值仍是精确普通状态 `D_S(v)` 所代表的真实可行树，所以只会增加等价工作，不会产生低于最优值的伪候选。另一方面，任何属于严格更优完整推导的必要 seed 或闭包值都通过 admissible 条件，因此不会漏掉改善 incumbent 所需的 branch。

## 9. 核心复杂度

令

```text
N_D = sum_(i=1..h) C(k,i),
N_A = sum_(i=0..c) C(k,i),
N_H = sum_(i=c+1..a) C(k,i).
```

### 9.1 Mask 关系数

ordinary split、低层 `A` 吸收和高层反向 strict-superset 边都可由

```text
sum_(S subseteq K) 2^|S| = 3^k
```

或等价的补集求和界住。所有目标的 completion 分割总数满足

```text
sum_(T subseteq K) 2^(k-|T|) = 3^k.
```

对固定根，转置的子掩码路线 probe 数为

```text
sum_(L present) (2^(k-|L|)-1) <= 3^k.
```

排序路线只在其精确预算内 pair probe 数不大于该值时执行，所以两条路线的实际组合工作都为每根 `O(3^k)`。终端事件数不超过 probe 数；同一 `<T,v>` 聚合后只保存一个值。

### 9.2 时间与空间

若一次多源图闭包成本记为 `C_G`，核心时间为

```text
O(g*C_G + n*3^k + (N_D+N_A+N_H)*C_G).
```

采用理论上的 Fibonacci heap 可取 `C_G=O(m+n log n)`；当前 `std::priority_queue` 实现按二叉堆口径计入相应对数因子。该上界说明伴随和转置没有把 mask 工作隐藏到超过 `O(3^k)` 的事件空间中。

令 `Q` 为实际保存的 `D/A/H` 根值总数，`E_T` 为聚合后的高层终端事件数，则核心空间为

```text
O(m + g*n + 2^k + Q + E_T),
```

最坏稠密时 `Q<=n(N_D+N_A+N_H)`、`E_T<=n*N_H`。sparse、dense 与 ranked-bitmap 只改变 `Q` 的字节表示，不改变状态集合。

锚树设施上界、dual 加强和 packing 的成本不属于上述核心式。它们的逐模块最坏求和见 `test152_full_complexity_audit.md`；完整实现仍为 `O(poly(g)(n3^k+2^k C_G))`，没有隐藏 `4^k` 枚举。复杂度门当前通过，但辅助模块是否值得进入最终方法仍由同源消融决定。

## 11. 当前结论与未完成项

本轮源码核对得到以下结论：

1. `A+D+D` 对重叠组、共享代表、锚点位于平衡根、零权边和空普通块是完备的。
2. strict root-irreducible `Br` 是标准同根递推的完备规范化基；严格 `<` 不会因等值或零权情形丢解。
3. 伴随实现的正确语义是两层 `F/H`：原始后缀 `F` 与闭包拉回 `H=C(F)`；源码与该递推一致。
4. 第一条跨切分边必须结算 `A+Br+H`，它与完整物化高层 `A` 等价。
5. directed-cut 转置逐目标保持 `G_T(v)`，两条枚举路线均受每根 `O(3^k)` 约束。
